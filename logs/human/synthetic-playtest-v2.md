# 합성 플레이테스트 2차

실제 배포 사용자가 아니라 가상 사용자 4명(공격적·안정적·회복 우선·혼합형)이 각 2런씩 선택한 결과다. 사용자가 실제 사람 대신 가상 사용자를 사용하도록 허용했다.

- 런: `run-40.json` ~ `run-47.json`
- v2 재생 결과: 4승 4패(50.0%)
- 목적: UI에서 제공하는 네 번의 경로 선택이 재생 파일로 합쳐지는지 확인
- 범위: 배포본 직접 브라우저 체감은 사용자 요청에 따라 생략
- 관찰: 액션 로그는 모두 재생 가능하지만, 전투 카드 순서와 요구 선택은 UI에서 직접 조작할 수 없다.
