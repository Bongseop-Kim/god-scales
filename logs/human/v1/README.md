# v1 — P-27 이전의 손 플레이 기록 20개

**다시 따지 않는다.** `Action`의 갈림길이 `"combat" | "rest"`에서 `"1:elite"`(갈래:종류)로 바뀌었고, 옛
`"combat"`은 **어느 갈래였는지 정보를 안 갖는다**. 호환 해석을 넣으면 재생은 되지만 같은 런이 아니고,
그러면 검사가 아니라 통과 의식이 된다.

이유는 지도만이 아니다 — P-25가 적을, P-31이 토큰과 파워를 바꾼 순간 이 기록들은 이미 다른 게임의
기록이다. **재생 결정론은 엔진 검사지 기록 보관이 아니다.** 지금 그 검사를 서게 하는 것은 셋이다:

- `test/fusion.test.ts` · `test/ui.test.ts` — 같은 실행 안에서 두 런을 맞댄다
- `npm run e2e -- --dist` — 배포본을 브라우저로 완주하고 반출한 JSON을 CLI가 그대로 재생한다
- `npm run sim -- --replay <파일>` — 지금 규칙판에서 딴 기록이면 그대로 돈다

새 판의 기록은 `logs/human/`에 다시 쌓인다(`npm run play`).
