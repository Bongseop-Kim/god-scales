# 합성 플레이테스트 v1 · 폐기된 캘리브레이션

실제 사용자 데이터가 아니라 사용자가 승인한 **가상 사용자 시뮬레이션**이다. UI 밀도 점검은 사용자 지시에 따라 제외했다.

아래 결과는 `bot_policy_version=v1` 당시의 기록이다. P-20에서 실제 신 조합을 실행하도록 고치고 봇 정책을 v2로 올렸으므로 현재 회차 지표에는 섞지 않는다.

## 정성 답변

- 휴식과 전투: 전투 고정 2런은 모두 패배했고 전휴식도 1승 1패라 선택에 실제 결과 차이가 있었다. 혼합 경로 4런은 2승 2패였다.
- 역린 회복: 아테나는 8런 중 5런에서 호의 0까지 내려갔다. 현재 CLI에는 요구 선택이나 회복 행동이 노출되지 않아 회복 불가능하게 느껴진다.
- 상충 요구: 현재 CLI가 상충 요구 선택을 입력받거나 표시하지 않아 이유를 관측할 수 없다. P-17 UI에서 선택과 대가를 노출해야 한다.
