# P-17 리뷰 · UI 골격

판정: React 마이그레이션 및 자동 검증 통과. Aside 브라우저 확인은 계정 크레딧 부족으로 미실행.

- `createRoot`와 React 컴포넌트로 시드 입력, 12층 지도, 네 경로 선택, 결과·로그·JSON 반출을 구현했다.
- 화면·시드·action log·결과 참조만 React 상태로 두고, 게임 계산은 기존 `sim/engine.ts`에 유지했다.
- UI와 CLI가 `sim/engine.ts`를 공유하며 재생 승패·층·호의가 일치한다.
- 클라이언트 저장소 문자열은 없다.
- React 정적 렌더 테스트를 추가했고 전체 51개 테스트가 통과했다.
