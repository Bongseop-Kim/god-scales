# R-73 · 화면에 있는 것은 전부 사전에서 찾을 수 있다

[P-73] 수행 결과. **엔진·규칙·카드 데이터는 건드리지 않았다.** 기존 변환표와 `cards.json`,
`intentBits`, 호의 경계를 그대로 사전에 연결했고 새 데이터 파일이나 새 오버레이는 만들지 않았다.
전역 버튼은 「사전」, 오버레이 제목은 전체 범위를 드러내는 「게임 사전」으로 정리했다.

## 한 일

- `conditionText`에 `turn > 3` → 「4턴부터」, `enemy_count() >= 2` → 「적 둘 이상」을 더했다.
  회귀 테스트는 `cards.json`과 `graces.json`의 모든 `when`을 함께 검사한다.
- 「카드 기호」에 뽑기·에너지·자해·호의·연쇄와 소멸을 설명했다. 소멸 카드 4장은 기존 우상단
  `card-kind` 슬롯에 「소멸」 배지를 표시한다.
- 파워 6장은 `cards.json`에서 골라 기존 `triggerLabels`와 `effectText`로 이름·발동 시점·효과를
  사전에 표시한다. 이름·발동 시점 열은 내용 폭을 확보해 줄바꿈하지 않고, 전투 파워 칩의
  `aria-label`에도 같은 효과 설명을 실었다.
- `intentBits`를 사전과 전투 화면이 함께 쓰도록 옮겼다. 공격·방어·회복·토큰·호의·대기와 의도 감춤을
  「적 의도」에 설명했다.
- 「신과 호의」에 기존 `favorBoundaries` 기반 네 단계와 은총의 다음 은혜 격·융합 전제를 설명했다.
  늘어난 내용은 기존 `.overlay-body` 세로 스크롤 안에만 놓였다.
- 토큰 스택은 배지 뒤 겹을 없애고 기존 우상단 숫자 하나로만 표시한다.
