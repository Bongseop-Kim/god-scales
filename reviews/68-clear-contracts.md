# R-68 · 과업은 맵에서 받고, 개입은 전투에서 자동

[P-68] 수행 결과. 전투 시작의 요구·승부 카드·최대 체력 예치와 전투 중 신탁 결정을 삭제하고,
`omen`을 다음 판정 가능한 전투 한 판에 쓰는 단일 `과업` 슬롯으로 바꿨다.

## 한 일

- 과업 노드는 두 후원 신과 `지나간다`만 제시한다. 신을 고르면 기존 `takeSide`로 상대 호의를 즉시
  내리고, 새 선택은 기존 과업을 교체하며 지나가기는 그대로 유지한다.
- 적 수가 모자란 전투에서는 과업을 관측과 HUD에서 숨긴 채 유지한다. 판정 가능한 전투에서는 단조
  사실로 달성·미달성을 잠그고, 승패와 무관하게 전투 종료 뒤 슬롯을 한 번 비운다.
- 모든 승리는 기본 3택 보상을 먼저 연다. 과업 달성 승리만 고른 신의 호의 +12와 그 신 카드 3택을
  한 번 더 열며, 미달성은 기본 보상만 준다.
- 일반 전투는 첫 카드 결정으로 바로 들어간다. 개입은 2·5·8턴에 선택 없이 적용하고 HUD의 남은 턴은
  `intervenesOnTurn`에서 계산한다.
- 상태 바와 전투 HUD에 과업 한 줄을 고정하고, 달성 컷인은 기존 `speak`와 신 초상을 재사용했다.
  줄인 모션에서도 같은 그림과 문구가 입력 없이 남는다.
- 도움말과 플레이어 UI 용어를 `과업`·`개입`으로 정리했다. 과업 보상은 전체 페이지 대신 선택한 신의
  카드 세 장과 확정 결과 한 줄만 보여 준다.
- replay의 `bet_card`·`oracle` 액션과 관련 봇·화면·스타일을 삭제했다. `rewardOffer`는 기본 보상과
  단일 신 과업 보상이 함께 쓰도록 `readonly string[]`만 받게 넓혔다.
