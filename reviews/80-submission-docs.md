## 캡처 — 계획대로 LLM이 aside로 게임을 플레이하며 촬영했다

`aside repl`(모델 없음)로 배포 URL(`?seed=2132`, e2e와 같은 시드)을 열어 e2e의 클릭 정책을 단발 스텝으로 옮긴 드라이버를 심고, **12층 완주 한 런 안에서** 필수 6샷 + 예비 7샷을 전부 찍었다. 스크린샷은 `tab.screenshot()` 버퍼를 base64로 stdout에 실어 파일로 복원(aside 세션 밖 경로 쓰기가 막혀 있다). 캡처 해상도는 1440×900 그대로 나온다 — 뷰포트 보고값(1614×709)과 다른데 화면 실측이 정본이다.

- 필수 6샷: 신 선택 · 맵 3갈래 · 전투 대상 지정 · 개입 컷인 · 은혜 3택1 · 결과(승리 12/12층)
- 개입 컷인은 500ms~3s 창이라 매 결정 직후 `.fx.{단계}`·`.voice.l2/l3`를 폴링해 첫 발생을 잡았다 — 런당 개입이 수십 회라 한 런이면 충분하다
- 주석(라벨·연결선)은 계획대로 HTML/CSS 오버레이다. 이미지 편집 툴 0회

## 실측이 계획을 고친 자리 셋

1. **ATTRIBUTION의 "SFX 9개(Kenney)"는 사실이 아니었다** — 실제는 Kenney Casino Audio 4개 + **Mixkit 5개**(`public/ATTRIBUTION.md`가 이미 정본이었다). 루트 파일을 public 기준으로 동기화하고 문서 B의 출처 표도 그 값으로 적었다. 낡은 것은 사운드 절만이 아니라 **아이콘 절도**였다(문자 심벌이라던 것이 game-icons.net 28개 CC BY 3.0) — 같이 고쳤다.
2. **"7줄 헌법"은 6줄이다** — CLAUDE.md 전문을 인용하는 문서가 줄 수를 틀리면 인용 전체의 신뢰가 깎인다. 문서 B는 "여섯 줄"로 적었다.
3. **프롬프트 14종은 13종**(card·demand·enemy + fusion 10), **pass_rate 사례 "0.8→1.0"은 실제 로그에 없다** — 실존하는 제우스 회차(30장→20 통과 0.67 → 반송 키 포함 재생성 10장→7 통과)로 교체했다. 표지 배경도 게임 캡처가 UI 버튼과 겹쳐 `art/hero/hero-title.webp` 원본으로 갈았다.
