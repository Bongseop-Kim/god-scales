# P-18 리뷰 · 연출과 에셋 배선

판정: 자동 검증 통과, 브라우저 확인 생략.

| Before | After | Why |
|---|---|---|
| 즉시 화면 교체 | 200ms `ease-out` 진입 | 급격한 상태 변화 완화 |
| 버튼 피드백 없음 | 120ms `scale(.97)` press | 고빈도 입력의 즉각적 피드백 |
| 모션 접근성 없음 | reduced-motion에서 이동 제거 | 움직임 민감 사용자 지원 |

- 카드·FX·오디오가 없어도 placeholder·무음으로 완주한다.
- 외부 아이콘 다운로드가 실패해 문자 심벌을 직접 만들었고 귀속 문서에 사실대로 기록했다.
