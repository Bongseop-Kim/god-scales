# R-51 · 카드별 아트 179장

`reviews/51-card-art.md` · [색인](00-index.md) · 관련 [R-32](32-art.md) · [R-41](41-cardface.md)

## 결론

**통과 · 완료 정의 전부 충족.** 카드 179장이 모두 `art/cards/{card_id}.webp` 320×240 q80 배포본을 갖고, 비융합 169장의 1536×1024 PNG 원본은 `art/_src/cards/`에 남았다. 기존 `{god}_{tag}` 폴백 20장은 제거했고 융합 10장도 320×240으로 통일했다.

GPT-image 2.0 내장 생성 경로로 카드 이름과 태그에서 모티프를 만들었다. 제우스 스타터 3장을 먼저 89×67로 기존 아트와 나란히 확인한 뒤 신별로 생성했다. 첫 변환에서 번들이 4.10MiB였고, 10KB를 넘은 신규 카드 27장은 q80을 낮추지 않고 빛 면적을 12% 아래로 제한해 재생성했다. 최종 번들은 **3.94MiB**다.

## 구현

- `art/_src/cards/subjects.json`: 비융합 카드 169장의 영어 주제문
- `art/_src/gen-docs.mjs`: 카드 데이터와 주제문을 조립해 169개 사이드카와 변환 명령 생성
- `art/cards/`: 카드 ID와 같은 WebP 179장·사이드카 179장
- `tools/art.ts`: 카드 기대값 `30 → 179`, ID 1:1 대조
- `ui/art-keys.ts`·`ui/card.tsx`: 179장 실상으로 주석 갱신. 매핑 함수는 바꾸지 않았다

## 눈으로 본 것

`aside`에서 1440×900으로 세 화면을 확인했다.

- 전투 손패: 아테나 `방패 세우기`/`성벽 밀치기`가 방패와 충돌하는 성벽으로 갈렸다
- 보상: 제우스 `구름 방패`/`천 개의 벼락`이 구름 덩어리와 흩어진 낙뢰로 갈렸다
- 덱 편집기: 제우스·아테나 각 3종이 모두 다른 구도였다. 같은 카드의 복사본만 같은 그림을 썼다
- 깨진 이미지 0, 콘솔 오류·경고 0, 실패 요청 0. 지연 로딩 이미지는 스크롤 뒤 모두 320×240으로 로드됐다
