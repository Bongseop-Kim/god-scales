## 결론

## 최종 검증

- `npm test`: 19파일, 63테스트 통과
- `npm run build`, `npx tsc --noEmit`: 통과
- 64,000런 6회차: 승률 30.2%, 조합 표준편차 18.80%p, 블록 효율 0.812, 합성률 6.3%
- 조합 행렬: 최저 셀 0.034 → **0.061**, 최고 셀 0.866 → **0.640**
- 회차 분산: 0.0829 → **0.0353, 감소** — 판정 규칙은 측정 전에 `reports/round-6/criterion.md`에 적었다. 압축 교란은 변동계수 0.7628 → **0.6231**로 배제했다
- 브라우저: `npm run e2e -- --dist`가 배포 산출물로 **12층 완주**(시드 141, 503결정) → 반출 → CLI 재생 일치, 여덟 화면 1440px 레이아웃 통과

## 남은 작업

P-22·P-23·P-24가 끝났다([22-pool.md](22-pool.md) · [23-round6.md](23-round6.md) · [24-finish.md](24-finish.md)). **B-0은 "매일 재확인" 하나만 남았다.** 에셋(일러스트 15장)은 다른 장비에 있어 이번 범위 밖이다.

- **완화의 종류를 구분하지 못하는 가중치.** P-22의 최대 발견이자 최대 부채다 — `displace`·`deflect`는 적 공격 크기(1층 6~10 → 12층 14~22)에 비례해 막고 `block`은 고정인데 게이트는 셋을 고정 가중치로 잰다. 근거는 [22-pool.md](22-pool.md)의 「가설은 절반만 맞았다」
- **상한이 목표선이 됐다.** 아테나 0.288 · 포세이돈 0.299 · 제우스 0.291로 세 신이 상한에 몰렸다
- `demand_zeus_solo` 지킴률 0.738 — 대역(0.17~0.65) 위. 제우스만 요구가 둘이므로 조이는 대신 지우는 것이 맞다
- **공개 URL의 번들이 P-21 시점이다.** 6회차 콘텐츠가 안 올라갔다 — 푸시 지시가 있어야 한다
- **B-0 "매일 재확인".** 최종 게이트가 Aside 앱을 요구해 Actions에서 못 돈다. 헤드리스를 붙이거나 매일 도는 것을 `npm run sim -- --replay`로 낮춘다
- 시작 덱 15장 일러스트, 스프라이트, 사운드

## 다음 기획 (P-25~P-31)

전투가 얕다. 적 7종 중 5종이 한 줄짜리 `damage N` cycle이고 **패시브라는 개념이 없다** — 적은 매 턴 같은 일을 하고, 플레이어가 무엇을 하든 반응하지 않고, 서로를 모른다. 슬레이 더 스파이어는 적 전용 파워만 40종이 넘는다. 그리고 **지도에 갈림길이 없다** — 12층 런에서 지도 결정이 두 번, 그것도 「쉴까 말까」뿐이다. 일곱 계획이 그 위에 선다.

권장 순서 — 번호가 아니라 이 줄이 실행 순서다:

[P-25 적 개성](../plans/25-enemies.md) → [P-26 HUD](../plans/26-hud.md) → [P-27 루트와 편성](../plans/27-map.md) → **[P-31 지속 효과](../plans/31-powers.md)** → [P-28 은혜](../plans/28-boon.md) → [P-29 퀘스트](../plans/29-quest.md)

**P-31이 P-28 앞이다.** 은혜는 카드와 같은 `Effect` DSL을 쓴다 — 어휘(`power`·`doom`·`thorns`)가 굳기 전에 은혜 45개를 뽑으면 전부 다시 만든다.

[P-30 신의 개입](../plans/30-intervention.md)은 P-25만 있으면 되고 나머지와 독립이다. **진노가 죽어 있다** — 4000런 층화에서 `wrath_ratio=0.000`이고, 포세이돈 진노 오라(`displace` → self)는 소모 경로가 없어 아무 일도 하지 않는다. 진노 신을 만들기 전에 진노에 닿게 하는 것이 그 계획의 앞 절반이다.

전부 콘텐츠 변경이다. **6회차 측정이 끝나 착수 조건은 풀렸다** — 다만 손대는 순간 7회차는 6회차와 비교 대상이 된다. 콘텐츠만 바꾸고 전역 파라미터·룰 봇 정책을 그대로 두면 기준선은 살아 있다(P-23이 그 선례다).
