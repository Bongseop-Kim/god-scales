# R-72 · 마지막 타격도 화면에 도착한다

[P-72] 수행 결과. 규칙·카드 데이터·봇·리플레이 액션은 바꾸지 않고, 전투를 끝낸 행동의 마지막 관측을
기존 결정 경로에 선택 필드 `finale`로 실어 아웃트로가 재생하도록 연결했다.

## 한 일

- `startTurn` 전후 체력을 비교해 턴 시작 파워 피해를 `hitSource: "power"`로 기록한다. 기존
  `recordHits`의 카드 공격 조건을 그대로 써 과업 사실과 대신 맞기에는 섞이지 않는다.
- `playEncounter`가 끝날 때 기존 `observation()`을 한 번 더 호출한다. 승리 관측은 첫 보상 결정의
  `observation.finale`, 패배 관측은 `RunResult.finale`로 전달한다. 결정 수와 options는 그대로다.
- App 아웃트로가 승패뿐 아니라 `finale`도 들고 `CombatScreen`에 넘긴다. 마지막 손패·체력·피해·적
  상태가 그려지므로 낸 카드는 퇴장하고 대상 선택 힌트와 화살표는 즉시 사라진다.
- 공격 막타는 기존 적 배열을 돌진 도착 시각까지 유지한 뒤 마지막 적 배열로 바꾼다. 비접촉 카드·개입·
  파워 막타는 마지막 피해를 기존 배우에게 한 렌더 전달한 직후 퇴장시킨다. 기존 피해 팝·플래시·사망
  프레임을 재사용했고, App의 임시 적 사망음 우회는 삭제했다.
- 회귀 검사로 카드 막타의 손패·피해·적 소멸, 파워 막타의 `power` 출처, 패배 막타의 플레이어 피해를
  고정했다.

## 검증

| 명령 | 결과 |
|---|---|
| `npx tsc --noEmit` | 통과 |
| `npm test` | 24파일 192테스트 통과 |
| `npm run build` | TypeScript·Vite 빌드 통과 |
| `npm run e2e` | Aside 329결정 12층 완주 + 자유 덱 38결정 · 9개 화면·반출 재생 통과 |
| `git diff --check` | 통과 |

`finale`는 결과 통계와 replay 파일에 반출하지 않는다. 카드·규칙 수치가 불변이므로 밸런스 게이트는
돌리지 않았다. 추적의 표식은 피해 없는 utility로 유지했고, 사냥감 표식과 표식 화살의 효과 순서도
관찰만 남기고 바꾸지 않았다.
