# R-77 · 플레이 피드백 넷

[P-77] 수행 결과. 카드 비활성 이유, 감소값 색, 최소 화면 크기, 빠진 hover 설명을 UI에서만
고쳤다. 엔진·전투 수치·밸런스 게이트는 바꾸지 않았다.

## 한 일

- 손패 카드가 비활성일 때 에너지 부족은 `data-why="energy"`, 에너지가 충분하면
  `data-why="reach"`로 구분했다. 전자는 비용 젬, 후자는 사거리 칸만 붉힌다. 대상 선택 중에는
  이유를 달지 않는다.
- 침수·훼방으로 낮아진 카드 수치를 진영 규칙의 해로움 색 `--bane`으로 바꿨다. 진노 출처를
  나타내는 카드 테두리는 기존 붉은색을 유지했다.
- 1200×720 미만에서는 CSS 미디어 쿼리만으로 지원 크기 안내가 판 전체를 대체하게 했다.
  게임 DOM과 상태는 그대로 남아 창을 키우면 즉시 돌아온다.
- 에너지 젬, 뽑을 카드 더미, 적 패시브 칩에 기존 문장과 사전 데이터를 재사용한 네이티브
  `title`을 붙였다. 별도 툴팁 컴포넌트는 만들지 않았다.

## Aside 확인

- 실측에서 1200×900의 마지막 적 칸 오른쪽 끝은 정확히 1200px이었고, 1199×900에서는
  1199.5px로 잘리기 시작했다. 1200×720에서는 무대와 손패가 모두 뷰포트 안에 섰다.
- 1199×900과 1200×719에서 안내가 `display: grid`, 1200×720에서 `display: none`이었다.
- 실제 전투에서 에너지 0인 카드의 비용 젬은 `rgb(235, 136, 125)`였다. 칸 0·3 적이 사라진 뒤
  사거리 `▮▯▯▮` 카드 「번뜩임」은 비용 젬이 본래 색인 채 사거리만 같은 붉은색으로 섰다.
- 침수 뒤 감소 수치 두 개는 `rgb(110, 168, 216)`(`--bane`)였다.
- 에너지·뽑을 더미와 패시브 넷 모두 한글 `title`이 실제 DOM에 섰다.
