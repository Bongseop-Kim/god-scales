# R-54 · 상단 상태 바 — 타이틀 제거 · 세로 중앙 · 문구 정리

`reviews/54-statusbar.md` · [색인](00-index.md) · 관련 [R-53](53-overlays.md) · [R-26](26-hud.md)

## 결론

**통과 · 완료 정의 전부 충족.** `RunHeader`(h1 + 「시드 N」 eyebrow)가 사라지고 상단 상태 바
하나가 체력·방어·호의 미터 둘·위치·턴/덱·덱·약속을 든다. 결정 패널은 680 중앙 + 케니 프레임,
콘텐츠는 상단 바 아래 높이의 세로 중앙에 선다. 규칙·값·데이터·봇 불변.

## 구현

- **상태 바는 App에 산다** — 화면 전환 밖이라 런당 ~36번 다시 서지 않고, `FavorMeter`의
  경계 펄스 `useRef`가 런 내내 이어진다(화면 안에 두면 전환마다 리셋된다). 셸 밖 fixed +
  `zoom`을 스스로 지고 폭을 `100vw / fit`으로 벌려 좁은 창에서도 전폭이다. 내용은 셸과 같은
  1040 정렬: 좌 체력·방어 · 중 호의 미터 둘(40px에 눕는 flex 꼴 · 경계 눈금은
  `favorBoundaries` 그대로) · 우 위치·턴/덱 + **덱·약속 버튼**(P-53 오버레이를 연다 — 전역
  아이콘은 소리·토큰·도움말 셋만 남았다)
- **`FavorMeter`가 `combat.tsx` → `header.tsx`로 이사**했고 `PlayerActor`의 favor-row는
  지웠다(P-55의 「중복 표시 금지」를 여기서 선지급). 나머지 이동은 본문 무수정이다
- **타이틀 이양** — 은혜 「{신}의 은혜 · tier N」·신탁 「{신}의 신탁」이 요구의 `god-say` 꼴
  (초상 84 + 신 색 왼 테두리, `GodSay`로 공용화)로 선다. **새 대사 0** — 라벨뿐이다.
  쉼터는 질문이 이미 있고, 보상·지도는 아무것도 안 남겼다. 결과의 「승리/패배」는 남고
  「전투 기록」 소제목과 eyebrow의 「시드 N ·」은 지웠다
- **결정 패널 680 중앙** — 쉼터·보상·은혜·요구·신탁의 `.decision-panel.solo`. 예외 하나:
  rest_card만 `wide`(전폭 1040, 덱 전체가 깔린다). 케니 9-slice는 **청동으로 미리 물들인
  사본**(`panel-border-00{7,10}-bronze.png`, magick colorize)을 쓴다 — 원본이 흰 알파 PNG라
  CSS `filter`로 틴트하면 패널 내용까지 물들기 때문에 sepia 대신 에셋을 물들였다.
  주요 버튼(`.primary`)은 `010` 스킨이다 — `.kbtn`을 따로 안 만들었다(주요 버튼은 이미 전부
  `.primary`고, P-55의 턴 종료도 그 클래스다)
- **세로 중앙** — `.shell.run`(런 화면 여덟)이 `min-height: 100vh/fit` grid
  `align-content: center` + 상단 40px 패딩. `.shell:has(.run-header)` 규칙은 지웠다
- **상주 설명문 걷어내기** — 보상·은혜·신탁 힌트와 쉼터 조언 꼬리(「얇은 덱이…」·「같은 카드
  두 장 중…」)를 지웠다. 전부 P-53 도움말에 이미 있다. **결정 정보는 남았다** — 대가·보상·
  기운 뒤 값·「무엇을 밀어내는지」·지도 칸 설명
- e2e: 결과 eyebrow 대조를 「제우스 + 아테나 · 12/12층」으로. 반출 JSON 파일명·헤더 대조는
  그대로다(시드는 파일에 남는 것이 맞다)

## 하지 않은 것

- 전투 배치 — 상단 바 교체 + favor-row 제거까지만. 무대형은 P-55다
- 시작 화면(시드 입력 포함)은 P-56이다. 미디어쿼리·반응형 없음 — `--fit` 하나가 정본이다
