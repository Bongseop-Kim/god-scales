## 결론

**통과 · 완료 정의 전부 충족.** `art/fx/`는 `devotion`·`calm`·`anger`·`wrath`·`burst`·`strike` 여섯 장만 남고, `art/ui/dialogue.webp`가 붙었다. 단계 넷은 이제 방향으로 갈린다: 헌신은 내려오고, 평온은 가장자리에 머물고, 분노는 위로 물러나며, 진노는 아래로 누른다.

새 원본 `calm`·`anger`·`strike`·`dialogue`는 built-in ImageGen으로 평면 마젠타 소스를 만들었다. 첫 `anger`가 너무 굵고 밝아 균열 폭과 밝기만 한 번 낮췄다. 최종 프롬프트는 각 사이드카에 남겼다. 기존 `open`·`block`·`burst`는 살아 있던 원본에서 1536×960 배포본을 회복했고, 원본 이름은 기록대로 유지했다.

| 파일 | 원본 | 배포본 |
|---|---:|---:|
| `devotion` | `open.png` 1586×992 | 58.4KB |
| `calm` | 1536×1024 | 2.4KB |
| `anger` | 1586×992 | 6.1KB |
| `wrath` | `block.png` 1586×992 | 33.4KB |
| `burst` | 1586×992 | 66.3KB |
| `strike` | 1536×1024 | 23.9KB |
| `dialogue` | 1536×1024 | 113.5KB |

fx 여섯 장은 전부 WebP 무손실 알파 1536×960이고 개별 200KB 아래다. 접촉 시트에서 투명 경계, 중앙·하단 여백, 국소 낙하, 빈 대사창을 확인했다.

`stageCut`은 삭제된 `open`·`block` 대신 단계 이름을 가리키게만 고쳤다. 매핑 자체 삭제와 직접 경로 배선은 P-46 몫으로 남겼다. `tools/art.ts`의 fixed는 8 → 12, fx 여섯 + UI 프레임 둘을 대조한다.
