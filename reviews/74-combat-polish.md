# R-74 · 전투 다듬기

[P-74] 수행 결과. 과업 접근성, 피격 확인, 전면 사거리, 4칸 보스, 179장 스모크,
은혜 테두리와 융합 배치를 한 번에 정리했다. 새 밸런스 지표나 UI 상태는 만들지 않고 기존 생성기,
전투 관측, 카드 프레임과 융합 마크업을 그대로 확장했다.

## 한 일

- 모든 omen에서 다음 줄의 도달 가능한 레인(±1)에 전투·정예·보스 중 하나가 있도록 맵 생성 불변식을
  추가했다. 판정 조건을 못 채운 과업은 숨기지 않고 전투 약속 줄에 「이월」로 표시한다.
- 플레이어 피격은 이미 `recordHits` → `PlayerActor`의 숫자 팝과 hit pose까지 연결되어 있었다. 새 연출을
  겹치지 않고 실제 적 공격의 `DamagePop` 마크업 회귀 테스트를 추가했다.
- 공격 카드 115장 모두에 `reach`를 명시했다. 기존 32장은 유지했고 나머지 83장은 신별 전투 거리로
  배정했다. 하한을 지키기 위해 시작 카드 등 막힘을 만드는 일부 카드만 사거리를 넓혔다.
- 두 지역 보스에 `size: 4`를 주고 타입·전투 생성·관측·UI가 같은 적 참조를 네 칸으로 다루게 했다.
  실제 조우에서 데이터 크기를 `size: 2`로 다시 덮던 코드를 제거했다.
- 카드 인장 배지는 없애고 기존 카드 프레임 마스크에 회색/인장색 `conic-gradient`를 입혔다. 한 인장은
  색+회색, 두 인장은 두 신 색이며 미리보기는 같은 프레임에서 반투명 처리한다.
- 융합 마크업과 모션은 유지하고 CSS 그리드만 바꿔 작은 두 신을 위 좌우, 카드를 아래 중앙에 놓았다.

## 179장 전수 점검

`tools/card-smoke.ts`가 실제 `createCombat`·`executeCard`·`firePowers` 경로로 모든 카드를 한 번씩
발동한다. 결과는 `cards=179 failures=0 noops=0`이다.

점검 중 `card_zeus_24`의 조건은 `slot(target) >= 2`인데 사거리가 `03`이라 2번 칸에서 효과가 사라지는
불일치를 찾았다. 카드별 예외를 두지 않고 사거리를 `0123`으로 넓혔다. 브라우저 점검 중에는 보스 데이터의
`size: 4`를 실제 조우가 `2`로 덮는 공유 경로 결함을 추가로 찾아, `enemyDefinition`의 데이터 값을 그대로
쓰게 고쳤다.
