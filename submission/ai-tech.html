02
Rules

상시 지시는 여섯 줄, 규범은 파일 두 벌

커밋·푸시·PR 금지. 사용자가 그 턴에 시킬 때만.
`plans/NN-*.md` 수행이 끝나면 `reviews/NN-*.md`에 리뷰를 남기고 해당 plan 파일을 삭제한다.
밸런스 게이트는 조합 승률 하한 하나. 새 지표·밴드·회차 비교를 만들지 않고,
통과 못 하는 값을 테스트에 넣지도 깎지도 않는다.
브라우저 확인·E2E는 `aside` CLI로만 한다.
게임에 들어가는 한글 텍스트(대사·카드·요구·UI)를 쓰거나 고칠 때는 `WRITING.md`를 먼저 읽고 따른다.
UI·레이아웃·애니메이션을 만들거나 고칠 때는 `UI.md`를 먼저 읽고 따른다.

CLAUDE.md 전문 — 긴 규칙집은 AI가 안 읽는다. 헌법 여섯 줄만 상시로 준다.

WRITING.md

신별 문체를 종결어미 단위로 잠근다 — “대사에서 이름을 지워도 어미만으로 누군지 알 수 있어야 한다.” 아테나만 존댓말, 요구 수치는 한글 수사만.

UI.md

「레이아웃은 움직이지 않는다」 — 조건부 컴포넌트는 자리를 남긴다 · 애니메이션은 transform·opacity만.

Browser E2E

사람이 눈으로 하던 확인을 AI가 한다

  • (a) 12층 완주 E2E — 모델 없는 aside repl이 진짜 클릭만으로 완주, 반출 JSON을 CLI 재생과 대조. 결정열이 한 자리라도 다르면 실패 (tools/e2e.ts)
  • (b) UI 변경마다 시각 검증 — 리뷰 문서의 「Aside 확인 (1440×900)」 절에 가로 넘침·빈 칸·기하 실측. 이 제출물의 게임 캡처도 전부 aside가 촬영
  • (c) 탐색 플레이 — 요구사항만 주면 에이전트가 스스로 그 상황을 만든다 ↓

「부분 방어 피해 팝 순서」 검증 — 초록 방어량 4가 빨간 −5 왼쪽에 뜨는 것을 시각 확인한 뒤, 스스로 「방어 4를 가진 적」을 찾아 적 쪽 케이스로 넘어가는 중.

Balance Gate

지표는 하나, AI가 지표를 속이지 못하게

// tools/tune.ts
export const winFloor = 0.05;      // 테스트에 잠긴 유일한 게이트
export const releaseFloor = 0.25;  // 릴리스 목표 — 보고만, 게이트 아님
  • 헌법이 「통과 못 하는 값을 테스트에 넣지도 깎지도 않는다」를 못 박는다
  • 신 적 HP 140이 하한과 충돌했을 때 고친 것은 규칙이 아니라 숫자였다 (HP 100)
  • 6회차 64,000런에서 회차 간 승률 분산 0.0829 → 0.0353 — 판정 규칙은 측정 전에 먼저 적었다
  • 사람 개입과 AI 실수는 전부 human_intervened · ai_failures로 계측에 남는다 — LLM 에이전트 10런 완주 · 폴백 0건
