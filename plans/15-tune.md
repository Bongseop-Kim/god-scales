## 완료 정의

1회차가 전체 완주하고 아래가 기록된다.

```
tuning
  loop_iteration        1
  variance_before/after  회차 전후 승률 분산
  auto_adjusted          자동 조정된 카드 수
  enemy_adjusted         자동 조정된 적·조우 수
  pairing_flagged        조합 상호작용으로 분류된 카드 수
  discarded              3회 조정 후에도 이탈해 폐기된 수
  human_intervened       사람 개입 수 + 개입 사유
```

**`human_intervened`가 비어 있지 않다.** 비어 있다면 아무도 어려운 것을 시도하지 않았다는 뜻이다(T-9.3).

```bash
npm run tune -- --iteration 1
```

## 구현 노트

**핵심은 반송 경로다**(T-5). 밸런스 판단이 사람의 감각을 거치지 않고 루프 안에서 처리된다.

```
① 스키마 · 어휘 · 임계값 정의
      ↓
② LLM 대량 생성  ←──────┐
      ↓                 │ 반송
③ 자동 검증 게이트 ──────┤
      ↓                 │
④ 헤드리스 시뮬          │
      ↓                 │
⑤ 리포트 → 자동 조정 ────┘
      ↓
   data/ 반영
```

### 조정 순서와 근거 주체 (T-6 ⑤)

| 순서 | 조정 대상 | 근거 |
|---|---|---|
| 1 | 임계값을 벗어난 적·조우 수치 | 룰 봇. 임계값 위반은 절대 기준이라 계기만으로 판정된다 |
| 2 | 카드 간 상대 델타 이상치 | 룰 봇. 상대 비교가 계기의 본업이다 |
| 3 | 전역 파라미터 | **자동 조정 대상이 아니다.** P-13에서 동결됐다 |

**3번을 룰 봇 승률로 판단하면 계기의 서투름을 게임의 난이도로 오독한다.** 반대로 1과 2를 소수의 사람 런으로 판단하면 표본이 부족하다. 단계마다 답할 수 있는 주체가 정해져 있다.

### 자동 조정 규칙

- 임계 이탈 카드의 수치를 조정하고 재시뮬한다
- **3회 조정 후에도 이탈하면 폐기하고 ②에 재생성을 요청한다**
- 특정 조합에서만 이탈하는 카드는 조정하지 않고 `pairing_flagged`로 분류한다(T-7)
- 조건 발동률 추정치를 시뮬 결과로 갱신한다 — **게이트는 회차가 늘수록 정확해진다**(T-6)
- `enemy_count_dist` 실측으로 `all_enemies` 평균 적 수 계수를 갱신한다

### 정직성 (T-9.3)

**`human_intervened`와 `ai_failures`를 이 세션에서 몰아 쓰지 말고 그때그때 적는다.** 마지막에 몰아 쓰면 기억으로 쓰게 되고, 기억으로 쓴 실패 목록은 성공 사례만 남는다. 성공 사례만 남은 로그는 데이터가 아니라 홍보물이다.

**여기서부터 B-0의 승격 조건 2번(3회차 완주)이 카운트된다.**
