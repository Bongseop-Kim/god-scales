## 완료 정의

- `runs_by_pairing`이 10칸에 균등하다 (칸 간 편차 5% 이내)
- `win_rate_matrix`가 10칸 전부 채워진다
- 조합별 승률 표준편차가 리포트에 나온다 (기대 8%p 이하)
- `card_win_delta`가 **조합 내에서 계산된 뒤 조합 간 평균된다** — 전체 풀에서 한 번에 계산하지 않는다
- 히트맵 이미지 1장이 파일로 나온다

```bash
npm run sim -- --runs 2000 --stratified
npm run report -- --heatmap
```

## 구현 노트

**이 세션의 산출물이 심사자가 보는 그림이다.** 파이프라인이 실제로 돌았다는 것을 한 장으로 보여주는 유일한 수단이다.

### 조합 교락의 통제 (T-7)

카드 성능이 어떤 신 조합에서 플레이되었는지에 의존하므로 카드별 승률 델타가 조합 효과와 섞인다. 방치하면 자동 조정(P-15)이 잘못된 대상을 건드린다. 상충 요구가 라이벌 조합에만 발생하고 단계별 전역 효과가 신마다 다르므로 이 교락은 강하다.

| 통제 | 방법 |
|---|---|
| 층화 시뮬 | 10개 조합에 런을 **균등 배분**. 조합을 무작위로 뽑지 않는다 |
| 조합 내 델타 | 카드 승률 델타를 조합 내에서 계산한 뒤 조합 간 평균 |
| 조정 대상 분리 | 특정 조합에서만 이탈하는 카드는 **조합 상호작용 문제**로 분류하고 자동 조정에서 제외, `pairing_flagged`로 별도 보고 |
| 기준선 | 아르테미스 포함 조합이 대조군 — 상충 요구도 없고 페널티도 없으므로 호의 압력의 순효과가 여기서 분리된다 |

### 읽는 법 (T-9.2)

**행렬에서 읽는 것은 칸의 절댓값이 아니라 칸 사이의 차이다.**

| 지표 | 기대 대역 | 벗어났을 때 |
|---|---|---|
| 조합별 승률 표준편차 | 8%p 이하 | 특정 조합이 붕괴했거나 층화가 깨졌다 |
| 라이벌 − 비라이벌 (룰 봇) | −5 ~ −15%p | 룰 봇은 은총 경로만 실행하므로 라이벌이 불리해야 정상 |
| `grace_earned` 순서 | 라이벌 > 비라이벌 > 아르테미스 | R-3.6의 예측. 어긋나면 R-4의 설계 의도가 성립하지 않은 것 |
| `fusion_rate` 순서 | 위의 역순 | 동상 |

**참조** — T-7 (조합 교락 통제), T-9.2 (주요 지표), R-3.6 (두 경로의 비대칭), R-9 (조합 수를 10으로 닫은 이유)
