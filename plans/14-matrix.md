## 완료 정의

- `runs_by_pairing`이 10칸에 균등하다 (칸 간 편차 5% 이내)
- `win_rate_matrix`가 10칸 전부 채워진다
- 조합별 승률 표준편차가 리포트에 나온다 (기대 8%p 이하)
- `card_win_delta`가 **조합 내에서 계산된 뒤 조합 간 평균된다**
- 히트맵 이미지 1장이 파일로 나온다

```bash
npm run sim -- --runs 2000 --stratified
npm run report -- --heatmap
```

## 조합 교락 통제 (T-7)

| 통제 | 방법 |
|---|---|
| 층화 시뮬 | 10개 조합에 런을 **균등 배분**한다 |
| 조합 내 델타 | 카드 승률 델타를 조합 내에서 계산한 뒤 조합 간 평균을 낸다 |
| 조정 대상 분리 | 특정 조합에서만 이탈하는 카드는 자동 조정에서 제외하고 `pairing_flagged`로 보고한다 |
| 기준선 | 아르테미스 포함 조합을 대조군으로 둔다 |

## 판정 대역 (T-9.2)

| 지표 | 대역 |
|---|---|
| 조합별 승률 표준편차 | 8%p 이하 |
| 라이벌 − 비라이벌 (룰 봇) | −5 ~ −15%p |
| `grace_earned` 순서 | 라이벌 > 비라이벌 > 아르테미스 |
| `fusion_rate` 순서 | 위의 역순 |

행렬에서 **칸 사이의 차이**를 읽는다.
