## 완료 정의

넷 다 통과한다.

**1. 연출이 상태를 새게 하지 않는다**
연출을 켠 상태로 브라우저 1런을 완주하고 반출한 JSON이 `--replay`와 일치한다. P-17과 같은 검사이며, **연출을 붙인 뒤에도 유지되는지가 이 세션의 핵심이다.**

**2. 연출을 꺼도 정보가 전달된다**
`prefers-reduced-motion: reduce`에서 1런을 완주한다. 어느 적에게 무엇이 들어갔는지, 어느 토큰이 붙었는지가 여전히 읽힌다.

**3. 일러스트가 없어도 깨지지 않는다**
`art/cards/`를 비운 상태로 1런을 완주한다. 모든 카드가 placeholder로 폴백한다.

**4. 스프라이트와 사운드 자리가 무음·무연출로 동작한다**
`art/fx/`와 `audio/`가 비어도 1런을 완주한다. 누락된 이펙트는 건너뛰고 누락된 소리는 나지 않는다 — 예외를 던지지 않는다.

```bash
npm run dev
#   1. 연출 on → 1런 → 반출 → npm run sim -- --replay  → 일치
#   2. DevTools 로 reduced-motion 강제 → 1런 완주
#   3. mv art/cards art/cards.bak → 1런 완주 → 복구
#   4. art/fx/ 와 audio/ 가 빈 상태로 1런 완주
npm run art -- --check     # 누락 목록 (지금은 전부 누락이 정상)
```

## 구현 노트

### 연출은 core 상태의 diff에서 나온다

**이것이 이 세션에서 유일하게 깨지기 쉬운 것이다.**

`ui/`는 `core/`를 읽고 action을 dispatch할 뿐이다(I-3). 연출을 붙이면서 UI가 "지금 피해 숫자가 날아가는 중"을 **게임 상태로** 갖기 시작하면 반출한 action 로그가 화면에서 일어난 일을 재현하지 못하고 완료 정의 1번이 깨진다.

```
action dispatch → core 가 새 state 반환
                → 이전 state 와 diff
                → diff 를 연출 큐에 넣는다   ← 표현 상태. 게임 상태 아님
                → 연출이 끝나든 말든 core 는 이미 다음 state
```

**연출 큐가 비어야 다음 action을 받을 수 있게 만들면 안 된다.** 그렇게 하면 연출이 게임 진행의 일부가 되고, 그 순간 UI가 상태를 갖는다.

### 연출이 플레이를 막지 않는다

애니메이션 중에도 입력을 받고, **다음 입력이 오면 진행 중인 연출을 즉시 완료시킨다.** 빠르게 두는 플레이어가 답답해지면 안 되고, 시연에서 연출 때문에 기다리는 것이 최악이다.

중단 가능해야 하므로 빠르게 반복 트리거되는 것(토큰 배지, HP 바)은 keyframes가 아니라 **transition**을 쓴다 — transition은 중간에 끊고 새 목표로 갈 수 있지만 keyframes는 0부터 재시작한다.

### 연출 목록과 규격

**A-2.6이 전체 표다.** 규칙은 하나 — **반복 빈도에 반비례해서 넣는다.**

| 빈도 | 연출 |
|---|---|
| 카드 사용 (런당 ~100) | press `scale(0.97)` 120ms. 그 이상 넣지 않는다 |
| 피해 숫자 (~200) | 대상 위에 팝 400ms — **어느 적에게 들어갔는가를 전달** |
| `chain` 파급 (~20) | 대상마다 60ms stagger — **파급을 광역과 구분** |
| 합성 카드 획득 (0~1) | **가장 크게.** 여기가 절정이다 |

```css
--ease-out:    cubic-bezier(0.23, 1, 0.32, 1);   /* 등장·소멸 */
--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);  /* 화면 내 이동 */
```

- **UI 피드백은 300ms 미만.** 스프라이트 극적 연출만 480ms+가 허용된다(A-2.6)
- **`ease-in` 금지.** 첫 순간을 지연시켜 굼뜨게 느껴진다
- **`transform`과 `opacity`만.** HP 바는 `width`가 아니라 `scaleX` — `width`는 레이아웃을 유발한다

### 라이브러리 — Motion 하나만

**`motion/react`를 넣고 GSAP과 canvas-confetti는 넣지 않는다.** 근거는 A-2.7에 있고 요지는 이것이다 —

Motion을 넣는 **유일한 이유는 `AnimatePresence`**다. CSS는 DOM에서 제거되는 요소를 애니메이션할 수 없고 React는 즉시 언마운트한다. **언마운트 지연을 손으로 관리하면 "화면에는 있지만 게임 상태에는 없는 요소"를 UI가 추적하게 되고, 그것이 이 세션의 완료 정의 1번을 위협하는 바로 그 상태다.** 화면 전환 · 손패 카드 퇴장 · 토스트 · 배너에서 반복된다.

**Motion을 쓰지 않는 곳** — press 피드백, 배지 펄스, 바 트윈은 CSS transition으로 둔다. 중단 가능성이 필요하고 라이브러리를 거칠 이유가 없다. 합성 카드 획득처럼 다단계 순차 연출은 WAAPI `await el.animate(...).finished` 15줄이면 되고, 그것 때문에 GSAP을 들이면 **어느 시스템이 이 요소를 잡고 있는지 알 수 없는 상태**가 생긴다.

### 스프라이트 시트 배선

**`background-position`이 아니라 `transform`으로 넘긴다**(A-2.8). `background-position`은 paint를 유발해 GPU 가속되지 않는다.

```css
.fx       { overflow: hidden; width: 256px; height: 256px }
.fx > img { animation: sprite 480ms steps(12) forwards }
@keyframes sprite { to { transform: translateX(-3072px) } }
```

`ui/fx.tsx`는 **시트가 없으면 조용히 건너뛴다.** P-21까지 `art/fx/`가 비어 있으므로 이 폴백이 기본 경로다.

### 사운드 배선

`ui/sfx.ts` — Web Audio 30줄. 버퍼를 한 번 디코드하고 재생마다 `AudioBufferSourceNode`를 만든다(겹침 재생). 첫 `pointerdown`에서 `ctx.resume()`으로 모바일 autoplay를 푼다. **파일이 없으면 무음이고 예외를 던지지 않는다.**

**음소거 스위치를 지금 만든다.** 소리 파일은 P-21에 오지만 스위치는 UI에 속하고, 나중에 붙이면 어디에 둘지 다시 정하게 된다. 기본값 켜짐, 첫 화면에서 끌 수 있게.

### 일러스트 규약

**카드 스키마를 건드리지 않는다**(A-2.3). `art/cards/{card_id}.webp` 파일 규약으로 연결하고, 없으면 placeholder로 폴백한다.

placeholder는 신 색 그라디언트 + 신 아이콘 워터마크 — CSS이므로 70장을 미리 만들 필요가 없다.

**이 세션에서는 일러스트를 그리지 않는다.** 카드 id는 회차마다 폐기·재생성으로 바뀌므로(T-6 ⑤) 지금 그리면 존재하지 않을 카드를 그리게 된다. 콘텐츠 동결 후 P-21에서 `npm run art -- --list`로 작업 목록을 뽑는다(A-2.4).

같은 이유로 **스프라이트 시트와 사운드도 여기서 만들지 않는다.** 이펙트는 카드 효과에 붙고 소리는 사건에 붙으므로, 카드가 폐기되면 그 이펙트도 함께 버려진다.

### 라이선스

**game-icons.net은 CC BY 3.0이므로 귀속이 라이선스 조건이다**(A-3.2). 아이콘마다 제작자가 다르므로 **받는 그 자리에서** 파일명에 기록한다 — 21개를 다 받은 뒤에 되짚으면 찾아야 한다.

`ATTRIBUTION.md`는 배포본에서도 접근 가능해야 한다.

### 이 세션은 미룰 수 있다

**P-19(배포)보다 뒤로 미룰 수 있는 유일한 세션이다.** placeholder로 화면이 완성되어 있고 일러스트 교체가 파일 드롭이므로, 배포를 먼저 하고 에셋을 나중에 얹어도 무방하다.

다만 **S-4 1번의 축소 대상은 장식이지 전달이 아니다.** 피해 숫자가 어느 적 위에 뜨는지, `chain`이 파급인지는 전투 로그 가독성(B-5)과 같은 등급이며 버리지 않는다.
