## 완료 정의

브라우저에서 1런을 완주하고, **반출한 JSON을 `npm run sim -- --replay`가 재생해 같은 결과를 낸다.**

```bash
npm run dev
#   → 브라우저에서 1런 완주 → 반출 버튼 → logs/human/run-*.json
npm run sim -- --replay logs/human/run-*.json
#   → 브라우저 런과 승패 · 도달 층 · 최종 호의가 일치
```

## 범위

| 이 세션 | 다음 세션 (P-18) |
|---|---|
| 화면 구조와 전환 | 아이콘 · UI 프레임 |
| `core/` 읽기와 action dispatch | 전투 연출 |
| 반출 버튼 | 카드 일러스트 자리와 placeholder |
| 신 색 5종 (A-2.5) | 배지 아이콘, `ATTRIBUTION.md` |

토큰은 임시로 한 글자만(감 지 침 벽 반 혈 광 표 치), 노드도 글자 하나(전 · 휴 · 보)로 둔다.

**최소 범위** — 전투 1화면 + 맵 목록 + 반출 버튼. 시작 시 남은 시간이 이틀 미만이면 전투 화면만 만들고 맵은 텍스트 목록으로 끝낸다.

화면별 구성 요소는 A-2의 표에 있다.

## 지시

- **`ui/`는 `core/`를 읽고 action을 dispatch한다**(I-3)
- React 상태는 "현재 어느 화면인가" 같은 표현 상태만 갖는다. 게임 상태는 전부 `core/`에 둔다
- 반출 형식은 P-12에서 확정한 `{seed, actions, replay_mode: "action_log"}`를 쓴다
- **클라이언트 저장소를 쓰지 않는다**(T-1.1)

```ts
const blob = new Blob(
  [JSON.stringify({ seed, actions, replay_mode: 'action_log' })],
  { type: 'application/json' })
```

**참조** — I-3, T-1.1, A-2, R-8.2, R-3.1
