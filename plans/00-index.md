## 세션 규약

- 각 파일에 실행하면 참/거짓이 나오는 명령이 하나 있다. **통과한 상태로 세션을 끝내고, 통과 전에는 다음 파일을 열지 않는다**
- 검증은 `npm test` 또는 `npm run sim` 한 줄로 만든다
- 각 세션은 커밋 하나 이상으로 끝내고 검증 명령을 `README.md`에 남긴다
- 문서 수정, 리팩터링, 이름 변경은 세션 사이에 한다
- **세션이 계획보다 길어지면 검증을 통과시킬 최소한만 만들고 넘어간다**

**소요 추정** — 짧음 ≈ 2~3시간, 보통 ≈ 4~6시간, 김 ≈ 8시간 이상. 전체 합 약 90시간. 1회차 실측으로 보정한다.

**부트스트랩 픽스처는 `core/__fixtures__/`에 두고 `data/`와 분리한다.** 경계는 P-01의 순수성 테스트가 검사한다.
