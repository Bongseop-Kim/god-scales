## 구현 노트

**배포본은 API 키 없이 실행된다**(T-1). LLM 호출은 `tools/` 아래 빌드타임 경로에만 존재하고 빌드 산출물에 포함되지 않는다. **이것이 정적 호스팅이 성립하는 조건이며**, `core/`의 네트워크 접근 금지(I-1)와 함께 확인된다. 위 grep 두 줄이 그 확인이다.

**서버도 데이터베이스도 환경 변수도 필요 없다.** 정적 파일을 URL 하나로 서빙할 수 있으면 무엇이든 된다(A-1.2). 배포 대상은 미리 정해져 있어야 한다 — 여기서 정하려고 미뤄두면 이 세션이 배포 도구 학습으로 채워진다.

**사람 플레이테스트 2회차를 여기서 돌린다**(A-4). 배포본으로 도는지 확인하는 것이 목적이고, 이번 런은 전역 파라미터 조정에 쓰지 않는다 — 동결(P-13) 이후이기 때문이다. 체감 기록만 남긴다.

**B-0의 4번 조건이 여기서 시작된다** — "배포본으로 1런 완주가 매일 재확인되고 있다". 배포 직후부터 매일 한 번 돌린다.

**참조** — T-1 (스택과 배포), T-1.1 (반출), I-1 (순수성), A-1.2 (배포 대상), B-0
