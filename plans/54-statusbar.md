# P-54 · 상단 상태 바 — 타이틀 제거 · 세로 중앙 · 문구 정리

관련 [P-53](53-overlays.md) 선행 · [R-26](../reviews/26-hud.md) · 목업 §0·§4·§6~§10 (https://claude.ai/code/artifact/b8958110-728f-4e1f-ad82-c1d1623a293d)

## 배경

게임인데 화면마다 「전투」·「쉼터」·「경로 선택」 제목이 선다 — 어떤 화면인지는 내용이
이미 말한다(요구·은혜는 신 초상, 쉼터는 질문 한 줄, 지도는 격자). 제목과 eyebrow가
세로를 먹고 콘텐츠는 위에 붙는다. 결정 화면 패널은 1040 전폭이라 선택지 버튼이
화면 끝까지 늘어난다. 「시드 1」은 개발자 표기다.

## 단계

### 1. `RunHeader` → 상단 상태 바

`ui/shared/header.tsx`의 `RunHeader`를 화면 전폭(1440) 슬림 바(높이 40, #090b11 78%)로
바꾼다. 내용은 셸 1040 정렬 — 좌: 체력·방어 · 중: 후원 둘 호의 미터(이름·값·단계색,
경계 눈금은 `favorBoundaries`) · 우: 위치·턴/덱 + **덱·약속 버튼**(P-53의 오버레이를
연다 — 전역 아이콘에서 둘을 빼 와 셋만 남긴다). **h1 제목과 「시드 N」 표기를 지운다.**
`data-phase`·`data-step`은 `app.tsx`의 섹션에 있으므로 무관하다.

### 2. 타이틀이 하던 일의 이양

- 은혜·신탁: 요구의 `god-say` 꼴(초상 84 + 신 색 왼 테두리)을 그대로 쓴다. 라벨은
  「아테나의 은혜 · tier 2」·「제우스의 신탁」 — **새 대사를 쓰지 않는다**(대사 신설은
  WRITING.md 신별 목소리 검수가 필요한 별도 작업).
- 쉼터: 질문 「어떻게 쉴까요?」가 이미 있다. 보상·지도: 아무것도 안 남긴다.
- 결과: 「승리/패배」는 결과 통지라 남는다. 「전투 기록」 소제목은 지운다.

### 3. 결정 패널 680 중앙 + 케니 프레임

쉼터·보상·은혜·요구·신탁의 `.decision-panel`을 680 중앙으로. 예외 하나 —
**쉼터의 카드 고르기(rest_card)만 전폭 1040**(덱 전체가 깔리는 자리, 한 줄 7장).
케니 9-slice 스킨: `art/kenney/panel-border-007.png`(패널)·`010`(주요 버튼),
`border-image` + 청동 틴트(sepia 필터), `image-rendering: pixelated`. CC0, 파일은
이미 `art/kenney/`에 있다.

### 4. 세로 중앙

상단 바 아래 남은 높이(860)의 중앙에 콘텐츠가 선다 — 지도 패널·결정 패널 전부.
`.shell:has(.run-header)`의 위 붙임 패딩 규칙을 중앙 정렬로 바꾼다.

### 5. 상주 설명문 걷어내기

P-53의 도움말로 이사가 끝난 문장들을 지운다 — 보상 힌트(「카드를 한 장 덱에…」),
은혜 힌트(「은혜는 카드 한 장이 아니라…」), 신탁 힌트(「저울은 한 조우에 한 번…」),
쉼터 detail의 조언 꼬리(「얇은 덱이…」·「같은 카드 두 장 중…」). **결정 정보는 남는다** —
대가·보상·기운 뒤 값·「무엇을 밀어내는지」·지도의 칸 설명 2줄.

### 6. e2e 갱신

`tools/e2e.ts:341`이 결과 eyebrow의 「시드 727 · …」를 대조한다 — 시드 없는 새 문구로
바꾼다. 반출 JSON 헤더 대조(340)는 그대로다(시드는 파일에 남는 것이 맞다).

## 하지 않는 것

- 전투 화면 배치는 안 건드린다 — P-55의 무대형이 상단 바 위에서 이어받는다. 이 플랜에서
  전투는 상단 바 교체 + 제목 삭제까지만.
- 시작 화면(시드 입력 포함)은 P-56이다.
- 미디어쿼리·반응형 추가 없음 — `--fit` 하나가 계속 정본이다.

## 완료 정의

- 여덟 런 화면에 h1이 없다. 상태 바 하나가 체력·호의·위치·덱·약속을 든다.
- 결정 패널이 680 중앙(rest_card만 1040)이고 세로 중앙에 선다.
- 화면 어디에도 「시드」·상주 규칙 설명문이 없다 — 전부 도움말·반출 JSON에 있다.
- 규칙·값·데이터·봇 불변 — 밸런스 게이트는 재측정하지 않는다.
