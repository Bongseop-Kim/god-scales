# P-40 · 자유 모드 — 시작 덱을 사람이 짠다, 게이트는 그것을 안 잰다

`plans/40-free.md` · [◀ P-39](39-tier.md) · [색인](../reviews/00-index.md)

**크기** 중간 · **착수 조건** **[P-38](38-patron.md) 완료.** 덱 편집기는 조합 선택 화면 옆에 선다 — 조합을 못 고르는데 덱만 고르는 화면은 없다. [P-39](39-tier.md)는 선택이다(티어가 없으면 전 카드가 tier1이라 아래 규칙이 그대로 돈다)

시작 덱은 규칙이 뽑는다 — 신별 attack·defend·utility 각 하나(최저 비용, `sim/engine.ts:37`)를 2·2·1 + 3·1·1로 열 장(`:335`). **런 시작 시점에 사람이 내리는 결정은 시드 하나뿐이다.**

이 계획은 그 열 장을 사람에게 넘긴다. 그리고 **그 모드를 밸런스 게이트에서 뺀다** — `tune`이 재는 것은 「조합 승률」이고 덱이 자유면 잴 대상이 사라진다.

---

## 완료 정의

**덱 열 장을 짜서 시작할 수 있고, 그 런이 반출·재생되고, `tune`은 그 모드를 한 번도 안 본다.**

```bash
npx tsc --noEmit && npm test
npm run tune                             # 조합 승률 하한 0.05 — 자유 모드를 부르지 않으므로 값이 안 움직인다
npm run e2e
```

| 항목 | 판정 기준 |
|---|---|
| 편집 | 열 장. 중복 허용, 신 무관. 열 장이 아니면 시작 못 한다 |
| 기본값 | 편집기는 **지금 규칙이 만든 열 장으로 차 있다** — 손대지 않으면 고정 모드와 같은 런이다 |
| 격리 | `npm run tune`·`npm run sim`의 결과가 한 자리도 안 바뀐다 |
| 반출·재생 | 자유 덱 런의 JSON이 그 덱으로 재생된다. 덱 없는 옛 파일은 규칙 덱으로 재생된다 |
| 입력 검증 | 파일이 들고 온 덱을 그대로 믿지 않는다 — 열 장·존재하는 id·**배포된 patron 카드 119장 안** |
| 게이트 | 하한 하나 그대로. 자유 모드용 지표를 **만들지 않는다** (CLAUDE.md) |

## 설계

### 1 · 격리는 코드가 아니라 호출부다

「자유 모드를 게이트에서 제외한다」에 분기가 필요할 것 같지만 아니다. **`tune`·`sim`·`heatmap`이 덱 인자를 안 넘기면 그것이 곧 제외다.**

```ts
export function* runSteps(seed: number, scenario?: Scenario, patrons: PatronPair = ["zeus", "athena"], deck?: string[]) {
  const startingDeck = deck ?? [ /* 지금 열 줄 그대로 */ ];
```

- 엔진에 모드 플래그가 없다. `deck`이 있으면 자유, 없으면 규칙 — **상태가 아니라 인자 하나**다
- `--free` 같은 CLI 옵션을 만들지 않는다. 만드는 순간 누군가 그걸로 게이트를 돌린다
- 자유 모드는 **화면과 replay 파일에만** 존재한다

### 2 · 반출 파일 — `deck`이 있으면 자유 모드다

[P-38](38-patron.md)이 `ReplayFile.patrons?`를 넣는다. 같은 자리에 하나 더:

```ts
export type ReplayFile = { seed: number; actions: ReplayAction[]; replay_mode: "action_log"; patrons?: PatronPair; deck?: string[] };
```

**별도 `mode` 필드를 만들지 않는다** — 모드는 `deck`의 유무로 이미 결정되고, 둘을 다 두면 어긋날 수 있는 두 번째 진실이 된다.

`readReplay`(`sim/replay.ts:18`)가 검증한다. **파일은 신뢰 경계다** — 여기 없으면 이상한 덱이 엔진 안에서 `cardMap.get(id)!`로 터진다:

- 길이 10
- 모든 id가 `data/cards.json`에 있다
- **`patron`을 가진 119장 안에서만** — 융합 10장은 은혜 둘을 모아 여는 보상이므로 시작 덱에 못 든다. [P-39](39-tier.md)가 서면 이 문장이 곧 「tier1만」이다(기존 119장이 전부 tier1이고 tier2는 신규다) — **그래서 이 계획은 P-39와 순서를 바꿔도 된다**
- 위반은 던진다. 조용히 규칙 덱으로 되돌리지 않는다 — 그러면 「재생했는데 다른 게임」이 된다

### 3 · 저울은 이미 돌고 있다 — 새 규칙이 없다

「조합을 맞출까 좋은 카드를 넣을까」의 대가는 **이미 코드에 있다**:

- `recordCardFavor`(`core/favor.ts:74`)는 어느 신의 카드든 그 신에게 +1을 준다(조우당 5회까지). **조합 밖 신의 호의는 아무것도 움직이지 않는다** — 은혜·개입·합성이 전부 `patrons`만 읽는다(R-26)
- `finishCombatFavor`(`:79`)가 조우마다 후원 신 호의를 −3 하고, **그 조우에 한 장도 안 쓴 신에게 −2를 더 깎는다**

즉 이방 카드로 덱을 채우면 후원 신 호의가 조우마다 −5씩 새고, 은혜가 안 오고, 융합이 안 열린다. **한 줄도 안 쓰고 저울이 선다.** 화면에 그 규칙을 한 문장으로 적어 두는 것이 이 계획의 일이다 — 지금은 어디에도 안 적혀 있다.

### 4 · 편집기 — 지금 덱을 채워 두고 고치게 한다

빈 열 칸에서 시작하면 129장을 훑어야 한다. **규칙이 만든 열 장을 미리 채우고 거기서 고치게 한다.**

- 슬롯 10칸 + 카드 목록. 목록은 신 다섯 탭으로 거른다 — 129장을 한 화면에 깔지 않는다
- 카드는 `CardRow`/`GameCard`를 그대로 쓴다(`ui/card.tsx`) — 보상 화면과 같은 그림이라 새 컴포넌트가 없다
- **중복 허용.** 지금 규칙 덱부터가 같은 카드 2·3장이다. 상한도 안 둔다 — 같은 카드 열 장은 나쁜 덱이지 막을 것이 아니다
- 조합 밖 신의 카드도 고를 수 있다. 그 슬롯에 **호의가 안 오른다는 표시**를 붙인다(§3)
- 열 장이 아니면 「런 시작」 `disabled` — [P-38](38-patron.md)의 「둘 아니면 못 누른다」와 같은 꼴
- 규칙 덱과 **완전히 같으면 `deck`을 반출에 안 적는다.** 그래야 편집기를 열었다 닫은 런이 고정 모드로 남고 e2e 기준선이 안 움직인다
- 접혀 있는 것이 기본이다 — 시작 화면이 한 눈금(900px, R-26)을 넘으면 안 된다

### 5 · e2e — 완주를 두 번 하지 않는다

시드 170 완주(428결정)는 **고정 모드 그대로** 둔다. 자유 모드는 체크포인트 하나로 충분하다:

- 편집기를 열어 한 장을 바꾸고 → 시작 → **첫 전투까지만** 가고 → 반출해 `deck`이 실렸는지 본다
- 12층 완주는 안 한다. 완주가 검증하는 것(엔진 진행)은 덱과 무관하고, e2e는 반복 루프가 아니라 체크포인트다
- 「자유 덱으로 열 조합이 다 시작된다」는 `test/`의 단위 테스트가 잡는다 — 브라우저가 필요 없다

## 배선

| 자리 | 무엇 |
|---|---|
| `sim/engine.ts:331` | `runSteps(..., deck?)` — 없으면 지금 열 줄 |
| `sim/engine.ts:647` | `run(..., deck?)` — 재생이 같은 덱을 탄다 |
| `sim/replay.ts:16` | `ReplayFile.deck?`, `readReplay` 검증 넷 |
| `ui/export.ts` | 규칙 덱과 다를 때만 `deck` |
| `ui/app.tsx` | 편집기(접힘 기본) · 슬롯 10 · 신 탭 · 시작 가드 |
| `ui/card.tsx` | 재사용만 한다 — 새 컴포넌트 없음 |
| `ui/style.css` | 슬롯 줄 |
| `tools/e2e.ts` | 자유 모드 체크포인트 |

**엔진 규칙·데이터·봇·게이트·동결 버전은 한 줄도 안 바뀐다.** 덱은 파라미터지 규칙이 아니다 — `globalParamVersion`·`botPolicyVersion` 그대로다.

## 함정

- **자유 모드는 아무도 안 재는 코드가 된다.** 그게 목적이지만 크래시까지 면제되는 건 아니다 — 「열 조합 × 자유 덱이 시작된다」 단위 테스트가 유일한 그물이다
- **`deck` 없는 옛 replay가 깨지면 안 된다.** 선택 필드인 이유다. `logs/`와 e2e 기준선이 여기 걸려 있다
- **덱 크기를 다이얼로 만들지 않는다.** 10 고정이다 — 열지 않으면 5장 덱과 20장 덱이 같은 게이트 밖에서 「자유 모드는 쉽다/어렵다」로 갈리고, 그건 모드가 아니라 난이도 슬라이더다
- **`cardMap.get(id)!`가 검증 없는 입력에서 터진다**(`sim/engine.ts:339`). §2의 네 줄이 그 자리를 막는 전부다
- **`rewardOffer`는 여전히 `patrons`만 본다.** 이방 카드로 덱을 짜도 보상은 후원 둘의 카드만 나온다 — 자유는 **시작 덱뿐**이다. 획득까지 자유로 열면 그건 다른 계획이고, 그때는 덱이 조합과 무관해져 조합 선택 자체가 장식이 된다
- **파워 카드 다섯 장을 시작 덱에 넣을 수 있다**(`power` 태그 — `card_zeus_23` 6.0 · `card_ares_24` 6.0 · `card_artemis_23` 7.5 · `card_athena_17` 5.8 · `card_poseidon_17` 5.7). 지금 규칙 덱은 attack·defend·utility 태그만 뽑으므로 파워가 시작 덱에 든 적이 없다 — 밸런스는 안 재지만 **`firePowers`가 1층부터 도는 경로가 처음 열린다**. 크래시가 있으면 여기서 난다
- **융합 카드는 목록에 없다.** `patron_pair`로 걸러 낸다 — 은혜 둘을 모아 여는 보상을 시작 덱에 넣으면 [P-39](39-tier.md)의 계단이 무의미해진다
- **화면 높이.** 편집기가 펼쳐진 시작 화면은 900px를 넘는다. 접힘 기본 + 펼친 상태는 스크롤을 허용한다 — e2e의 `halfEmpty` 검사는 setup을 안 본다

## 다음 자리 — 이 계획이 안 하는 것

1. **획득의 자유.** 보상 풀을 조합 밖으로 여는 것. 조합 선택이 장식이 되므로 저울(§3)이 실제로 결정을 만드는지 본 뒤다
2. **덱 프리셋 저장·공유.** localStorage 한 줄이지만, 반출 JSON이 이미 덱을 들고 있으므로 그 파일이 곧 프리셋이다
3. **자유 모드 통계.** 만들지 않는다. 게이트를 하나로 두는 이유가 그것이다 (CLAUDE.md)
4. **CLI 자유 모드.** `sim/play.ts`는 시드만 묻는다 — 덱을 물으면 파이프 입력의 자리 수가 바뀌어 기존 스크립트가 다 깨진다
