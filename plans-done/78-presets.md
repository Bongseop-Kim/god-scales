# 78 — 추천 조합 프리셋: 조합·호의 배분·덱을 한 번에 골라 시작한다

자유 설정(덱 편집기 + 호의 슬라이더)은 게임을 아는 사람의 도구다. 처음 온 사람에게는 124장과
슬라이더가 결정이 아니라 부담이다. **이름 붙은 프리셋** 몇 개를 시작 화면에 깔아, 하나 누르면
조합 둘 · 호의 배분 · 시작 덱 열 장이 한 번에 차고 바로 「런 시작」을 누를 수 있게 한다.

전부 UI 프리필이다 — 엔진·수치·밸런스 변경 없음. 프리셋은 기존 자유 모드 상태
(`picked`/`split`/`deck`, `ui/app.tsx:93,100,105`)를 채우는 버튼일 뿐이고, 채운 뒤에도
초상·슬라이더·덱 편집기로 계속 고칠 수 있다. 새 모드가 아니다.

---

## 1. 데이터: `data/presets.json`

게임 텍스트가 사는 자리(`cards.json`·`gods.json`)를 따른다. 항목 4~5개, 각각:

```json
{ "id": "storm_blood", "name": "폭풍과 피", "pair": ["zeus", "ares"], "split": 60,
  "text": "번개로 태우고 광란으로 밀어붙입니다. 손이 먼저 나가는 사람의 조합입니다.",
  "deck": ["…열 장…"] }
```

- `name`은 카드 이름 규칙(2~7자 명사구, WRITING.md), `text`는 UI 시스템 텍스트(합니다체,
  1~2문장)다 — 프리셋은 신이 아니라 게임이 권하는 자리다.
- `split`은 `pair[0]`의 몫(`favorPool` 기준, 슬라이더와 같은 축).
- `deck`은 열 장 명시. 기본은 `ruleDeck(pair)`(`sim/engine.ts:76`)에서 출발해 조합 컨셉에
  맞는 카드 한두 장을 `startableCards`(tier1) 안에서 바꾼 것 — 시작 덱 편집기가 고를 수
  있는 것과 같은 목록이므로 새 규칙이 안 생긴다.
- 다섯 신이 프리셋 어딘가에는 한 번씩 나오게 짠다 — 프리셋만 눌러도 다섯을 다 만나 본다.

## 2. UI: 시작 화면에 프리셋 줄

`ui/screens/setup.tsx`

- 신 초상 줄(`:242`)과 하단 줄(`:273`) 사이에 프리셋 버튼 줄을 둔다. 항상 보인다 —
  마운트 시점에 확정되고 안 바뀌므로 흔들림이 아니다(UI.md 제1규칙).
- 버튼 하나 = `name` + 신 색 점 둘(`--god-color` 변수, `god-legend`(`:133`)의 `<i/>`와 같은
  그릇) + `text`. 업적 배지 느낌은 이 이름·설명 카드 꼴로 충분하다 — 해금·달성 시스템을
  만들지 않는다.
- 누르면 `onApplyPreset(preset)` 하나만 부른다. 선택 상태를 따로 들지 않는다 — 누른 결과가
  초상 점등·덱 장수·배분 라벨로 즉시 보이고, 이후 편집하면 프리셋과 어긋나는 게 자연스럽다.

`ui/app.tsx`

- `applyPreset = ({ pair, split, deck }) => { setPicked([...pair]); setSplit(split); setDeck([...deck]); }`
  — 기존 세터 셋을 묶은 것이 전부다. `SetupScreen`에 prop으로 내린다.

`ui/style.css`

- `.preset-row` 한 덩이. hover는 `transform`만(UI.md).

## 3. 테스트

`test/free.test.ts`(자유 모드 검증이 이미 사는 자리)에 프리셋 무결성 하나:

- 각 프리셋: `pair`가 서로 다른 유효한 신 둘, `0 <= split <= favorPool`, `deck.length === deckSize`,
  모든 카드 id가 `startableCards`의 해당 목록에 있음, `id`·`name` 중복 없음.

승률 게이트는 건드리지 않는다 — 프리셋 덱은 편집기로 만들 수 있는 덱의 부분집합이라
기존 게이트 밖의 새 지표가 필요 없다(CLAUDE.md).

## 4. 완료 기준

- 시작 화면에서 프리셋 하나를 누르면 초상 둘이 켜지고 덱 버튼이 10/10장, 배분 라벨이
  프리셋 값을 보인다 — `aside`로 확인.
- 프리셋 적용 후 덱 편집기·슬라이더·초상 토글이 전과 똑같이 동작한다.
- 프리셋 없이 기존 흐름(직접 선택)도 그대로다.
- `vitest run` 전체 통과.
- 완료 후 `reviews/78-presets.md` 작성, 이 플랜 삭제.

## 이 플랜이 안 하는 것

- 업적·해금 시스템 — 프리셋은 처음부터 전부 열려 있다. 잠금은 진행 저장이 생긴 뒤의 이야기다.
- 사용자가 만든 덱을 프리셋으로 저장 — localStorage 저장 기능이 생기면 그때 별도 플랜.
- 프리셋별 승률 밴드·검증 지표 — 밸런스 게이트는 조합 승률 하한 하나뿐이다(CLAUDE.md).
