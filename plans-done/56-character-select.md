# P-56 · 인트로 메뉴 · 신 선택 캐릭터 셀렉트 · 시드 숨김

관련 [P-53](53-overlays.md) 선행(소리 아이콘) · [R-38](../reviews/38-patron.md) · 목업 §1~§2 (https://claude.ai/code/artifact/b8958110-728f-4e1f-ad82-c1d1623a293d)

## 배경

신 선택이 텍스트 칩 다섯이다 — 1024×1536 일러 다섯 장(`art/gods/`)이 있는데 시작
화면에서 안 쓴다. 「결정론적 덱빌딩 프로토타입」은 이제 사실도 아니다(프로토타입 아님).
시드 입력은 개발자 UI다. 시뮬 통계 링크가 시작 화면 구석에 산다.

## 단계

### 1. 인트로

eyebrow(「결정론적 덱빌딩 프로토타입」) 삭제. 메뉴를 제목 아래 좌측 세로 스택(폭 220)
으로 — **게임 시작(케니 버튼) · 시뮬 통계(stats.html 링크, 시작 화면에서 이사) ·
전체화면**. 우측 절반은 배경 일러의 자리라 비워 둔다.

### 2. 신 선택 — 캐릭터 셀렉트

`SetupScreen`의 `god-legend` 칩을 세로 초상 5장으로. 각 196×약 560(원본 2:3,
`object-fit: cover` 상단 정렬), 사이 2px 디바이더 4개 — 청동 그라데이션이 위→아래로
흐르는 shimmer 루프 2.6s(`prefers-reduced-motion`이면 정지).

상태 셋 — 기하는 CSS, React는 상태 클래스만:
- 기본: `grayscale(.78) brightness(.5)`
- hover/focus: 리프트 4px + 채도 복원 + 신 색 테두리, 120ms
- 선택: 원색 + 신 색 테두리·발광 + 이름판 점등 + 「선택 1·2」 배지

선택 로직 불변 — `toggleGod`의 `slice(-2)`(셋째가 가장 오래된 것을 밀어냄),
`aria-pressed`, 엔진 `gods` 순서로 굳히는 `patronPair`. **버튼이 그림이 될 뿐이다.**

### 3. 하단 한 줄

배분 슬라이더(폭 500, 둘 골라야 등장 — 현행 `SplitField` 그대로) · 시작 덱 편집기
(접힘 `<details>` 현행) · **런 시작(케니 버튼)** 오른쪽 끝. h1·lead·`pick-label`·
토큰 범례(→ P-53 토큰 사전)·소리 버튼(→ P-53에서 이미 삭제)·힌트 두 줄·통계 링크
(→ 인트로)를 지운다. 걷어낸 설명문은 P-53 도움말에 이미 있다.

### 4. 시드 숨김

`seed-field`를 지운다. 시드는 시작 시 `Math.random()` 기반으로 하나 만들어 state에
들고, **반출 JSON에는 그대로 남는다**(재현의 근거). 개발·e2e용은 URL 쿼리 —
`main.tsx`가 `?seed=`를 읽어 `App`에 넘긴다. 정수 검증(`setCustomValidity`)은
입력이 사라지므로 같이 죽는다.

### 5. e2e 갱신

`tools/e2e.ts:59`의 `tab.fill("input[type=number]", seed)`를 지우고 진입 URL에
`?seed=727`을 붙인다. 신 선택 클릭(아테나→제우스 순서로 정규화 검증)은 초상 버튼에서
그대로 동작해야 한다 — `aria-pressed` 셀렉터 불변.

## 하지 않는 것

- 신 소개문·능력 미리보기를 초상에 붙이지 않는다. 이름과 그림뿐 — 설명은 도움말이다.
- 덱 편집기 개편 없음. 접힌 `<details>` 그대로다.
- 신 테마 프롭 오버레이(목업 §12)는 P-58이다.

## 완료 정의

- 시작 화면의 주인공이 초상 다섯이다. 텍스트는 「후원할 신 둘 · N/2」와 하단 한 줄뿐.
- 화면 어디에도 시드 입력이 없고, `?seed=727` 진입과 반출 JSON 재현이 성립한다.
- 인트로에 시뮬 통계가 있고 시작 화면에는 없다.
- 규칙·값·데이터·봇 불변 — 밸런스 게이트는 재측정하지 않는다.
