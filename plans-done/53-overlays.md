# P-53 · 오버레이 넷과 전역 아이콘

관련 [R-52](../reviews/52-ui-split.md) · [R-26](../reviews/26-hud.md) · 목업 §3 (https://claude.ai/code/artifact/b8958110-728f-4e1f-ad82-c1d1623a293d)

## 배경

규칙 설명문이 화면마다 상주한다 — 보상·은혜·신탁의 힌트 문장, 시작 화면의 lead와 덱 편집기
설명. 걷어내려면(P-54) 먼저 **갈 곳**이 있어야 한다. 토큰은 hover title 한 줄이 전부라
13종을 한눈에 볼 자리가 없고, 런 중에 내 덱과 걸린 약속을 확인할 방법이 아예 없다.

넷 다 같은 꼴이다: 게임 위에 뜨는 모달, 배경 68% 어둡게, Esc·바깥 클릭·×로 닫기,
게임 상태는 그대로(엔진은 답을 기다리는 중이라 멈출 것도 없다).

## 단계

### 1. `ui/shared/overlay.tsx` — 모달 셸 하나

`<dialog>` 네이티브를 쓴다 — focus trap·Esc·backdrop이 공짜다. 폭 680 기본(덱만 920),
케니 프레임(§4). 열림 상태는 여는 쪽(App)이 든다. 라이브러리 없음.

### 2. 전역 아이콘 — `FullscreenButton`과 같은 규칙

fixed 우상단 8,8, 셸 밖, zoom 미적용, 평소 40% 불투명. **이 플랜에서는 다섯이다** —
소리 토글 · 토큰 사전 · 도움말 · 덱 · 약속. P-54의 상단 바가 생기면 덱·약속 둘이
그리로 이사하고 셋이 남는다(한 줄 이동이라 여기서 미리 나누지 않는다).
소리 토글은 시작 화면의 「소리 켜짐/꺼짐」 버튼을 **대체**한다 — 그 버튼은 여기서 지운다.

### 3. 토큰 사전

데이터는 `ui/shared/tokens.tsx`의 `tokenStyle` **하나에서** 만든다 — 사전용 사본을 만들면
같은 사실에 두 경로다. 이로움(`selfTokens`) 6종 외곽선 / 해로움 7종 채움, 배지 38 +
이름 + 지속 + 효과 한 줄. 배지는 `TokenBadge` 재사용.

### 4. 도움말

P-54가 걷어낼 문장들의 새 집. 항목 여섯 — 목표 · 저울(단계 경계는 `favorBoundaries`에서
읽는다) · 은혜 · 요구 · 쉼터(`restHealing`) · 시작 덱. 문구는 WRITING.md UI체(합니다체,
한 문장)를 따르고, **기존 화면 문장을 최대한 그대로 옮긴다** — 새로 쓰면 새로 검수해야 한다.

### 5. 덱 오버레이

읽기 전용. `GameCard` 재사용, 한 줄 6장, 세로 스크롤. 덱 목록이 지금 관측에 없는
phase(전투 등)가 있으면 `sim/engine.ts`의 observation에 싣는다 — **규칙·값 불변, 관측
확장이다**(UI가 게임 상태를 들지 않는다는 원칙이 정본).

### 6. 약속 저널

진행 중 → 지킴 → 깨짐 세 그룹. 진행 중은 관측의 `promises` 그대로. 히스토리는 App이
관측 스트림에서 `settled`를 수집해 쌓는다 — `actions` 배열과 같은 꼴의 표시용 누적이지
게임 상태가 아니다. 각 줄 = 신 색 + 조건(rule) + 층 + 결과.

## 하지 않는 것

- 오버레이 열림을 URL·저장에 싣지 않는다. 새로고침하면 닫힌 상태다.
- 도움말에 튜토리얼·단계별 안내를 만들지 않는다. 문단 여섯이 전부다.
- 덱 오버레이에 정렬·필터 없음. 뽑을 더미 순서도 안 보여준다 — 정보는 장수뿐.

## 완료 정의

- 우상단 아이콘 다섯이 모든 화면에 선다. 오버레이 넷이 Esc·바깥·×로 닫힌다.
- 소리 토글 버튼이 시작 화면에서 사라지고 아이콘으로 옮겨졌다.
- 토큰 사전의 13종이 `tokenStyle`과 같은 값이다(수동 사본 없음).
- 규칙·값·데이터·봇 불변 — 밸런스 게이트는 재측정하지 않는다.
