# P-57 · 토큰 아이콘 13종

관련 [R-33](../reviews/33-icons.md) · [R-37](../reviews/37-wire.md) · 목업 §0 교정 11 (https://claude.ai/code/artifact/b8958110-728f-4e1f-ad82-c1d1623a293d)

## 배경

토큰 배지가 `art/icons.svg`의 범용 글리프를 쓴다 — 종류는 갈리지만 개성이 없다.
레퍼런스(궨트식 스탯 아이콘 시트)처럼 토큰마다 전용 픽셀 아이콘을 만든다.
**배지 틀은 불변이다** — 38 원형, 이로움 외곽선/해로움 채움, 지속 3종 테두리, 진영색.
R-26의 채널 규칙(색만으로 말하지 않는다)이 그대로 산다. 바뀌는 것은 안의 그림 하나다.

## 단계

### 1. 생성 — 카드 일러와 같은 파이프라인

13종(`core/state.ts`의 `tokenNames`): 감전 · 밀려남 · 침수 · 방벽 · 반사 · 출혈 ·
광란 · 표식 · 치명 · 가시 · 위력 · 고갈 · 안개. GPT-image 생성 → `art/_src/tokens/`
원본 → magick 변환 → `art/tokens/*.webp`. **입·출력 경로를 같게 쓰지 않는다**(원본이
깎인다 — 프롭 md들의 규칙). 파일마다 `.md` 문서(기존 에셋 관례).

- 화면 24px(배지 38 안)에서 읽히는 실루엣 — 얇은 선 금지(R-33이 일곱 개를 간 이유).
- 형태가 뜻을 든다: 색·테두리는 배지 틀 몫이므로 아이콘은 무채색~단색으로 뽑아
  `--token-color`가 틴트하게 하는 쪽이 신 색 규칙과 맞는다.

### 2. 연결

`TokenBadge`의 `<Icon name={token} />`을 `art/tokens/` glob(eager) `<img>`로 바꾼다.
토큰 아이콘 13개가 번들에 실리므로 「안 뜰 때가 곧 앱이 안 뜰 때」 — 폴백을 만들지
않는다(R-33과 같은 판단). `icons.svg`의 토큰 심볼 10개는 다른 사용처(카드 효과 줄,
의도)가 있으면 남기고 없으면 지운다 — 두 자리가 같은 그림을 다르게 들지 않게 한다.

### 3. 게이트

`tools/art.ts`의 `--check` 대조 목록에 `art/tokens/` 13개를 넣는다 — `tokenNames`에서
목록을 만들어 **토큰을 새로 만들면 아이콘이 없다고 게이트가 막게** 한다. `size`
집계에도 들어간다(상한 4MiB — 32px webp 13장이면 수 KiB다).

## 하지 않는 것

- 배지 틀·지속 표기·툴팁 문구 불변. 사전(P-53)도 `TokenBadge`를 쓰므로 자동으로 바뀐다.
- 패시브 8종·의도 5종 아이콘은 안 건드린다 — 이 플랜은 토큰 13종만.

## 완료 정의

- `art/tokens/` 13장 + md 13개. 배지·사전·전투 발밑 칩이 전부 새 아이콘을 쓴다.
- `npm run art -- --check` 통과(13종 대조 포함), 번들 무게 상한 안.
- 규칙·값·데이터·봇 불변 — 밸런스 게이트는 재측정하지 않는다.
