# P-63 · 지도 화면 — 확대 · 마커 · 군더더기 제거

관련 [R-42](../reviews/42-mapwalk.md) 격자가 조작 면 · [R-54](../reviews/54-statusbar.md) 제목 정리 ·
[art/ui/marker.md](../art/ui/marker.md) · [UI.md](../UI.md)

## 배경

경로 화면은 **런당 12번 서는 자리**인데 판이 520px에 칸이 48px다(`ui/style.css:428`·`:432`). 1040px
셸 안에서 반만 쓰고, 나머지는 배경이다. 그 좁은 판 위에 안 필요한 글자가 셋 있다:

1. `<h2>지하 6층 × 3갈래</h2>`(`map.tsx:106`) — 격자가 보이는데 격자의 크기를 글로 다시 적는다.
2. `.node-hint` 두 줄(`:166`·`style.css:438`) — 「쉼터 — 체력을 회복하거나 카드를 지웁니다」. 쉼터가
   무엇인지는 12층 중 셋째 층이면 이미 안다.
3. 잠긴 칸에 뜨는 **금지 커서**(`button:disabled`, `style.css:88`) — 지금 서 있는 칸·시작 칸에 마우스를
   얹으면 「막힘」 표시가 뜬다. 못 가는 곳이 아니라 **방금 지나온 곳**인데 고장처럼 읽힌다.

마커는 16px다. 48px 칸의 모서리에 붙은 16px 그림이라 「내가 어디 있는지」가 한눈에 안 든다.

## 확인한 사실

- **결과 화면이 같은 `MapPanel`을 쓴다**(`result.tsx:49`) — 크기 규칙은 전부 `.walkable`에만 걸려 있고
  (`style.css:428~434`) 결과의 두 격자는 30px 칸으로 `.8fr` 열에 나란히 선다. **`.walkable`만 만지면
  결과 화면은 그대로다.**
- 마커 원본은 16×16이 곧 파일 크기다(`art/ui/marker.md`) — 임의 확대는 금지지만 **정수 2배는 픽셀이
  안 뭉갠다**(`image-rendering: pixelated`). 그 사이드카의 「그 이상 크면 칸을 넘는다」는 30px 칸을 두고
  적힌 문장이라, 칸이 커지면 같이 고쳐야 한다.
- `nodeDetail`(`map.tsx:11`)은 화면 줄만이 아니라 **`aria-label`도** 든다(`:137`) — 화면에서 지워도
  스크린 리더의 설명은 남아야 한다(접근성은 안 깎는다).
- 잠긴 칸도 `<button disabled>`라는 것을 테스트가 본다 — `test/ui.test.ts:440`이 버튼 16개 · 열린 셋 ·
  나머지 전부 `disabled`를 센다. e2e도 `button.map-node.open.rest`로 고른다(`tools/e2e.ts:174`).
  **버튼 구조는 못 바꾼다.** 커서와 hover 반응만 바꾼다.
- `text` prop을 지우면 `test/ui.test.ts:424`의 `walkable()` 헬퍼가 넘기는 인자도 같이 지워야 한다.
- e2e는 화면마다 `overflowX: false`와 「폭 0인 열 없음」을 잰다(`tools/e2e.ts:378`). 760px은 1040 셸 안이라
  넘치지 않는다.

## 단계

### 1. 판을 키운다 (`ui/style.css` — `.walkable`만)

| 자리 | 지금 | 이후 |
|---|---:|---:|
| `.map-panel.walkable` 폭 | 520 | **760** |
| `.map-wrap` 폭(`:532`) | 520 | **760** — 같이 안 키우면 보스 신호 프롭이 판 위로 들어온다 |
| 칸 높이 | 48 | **72** |
| 칸 아이콘 | 16 | **28** |
| 칸 이름 글자 | .62rem | **.74rem** |
| 층 번호 열 | 56 | **64** |
| 마커 | 16 | **32**(정수 2배) |

`.prop.boss-signal`(`:533`)의 `right: -72px`도 새 폭에 맞춘다. `art/ui/marker.md`의 「주의」 첫 줄을
새 칸 크기로 고친다 — 사이드카가 화면과 어긋나 있으면 다음 사람이 같은 실수를 한다.

### 2. 글자 셋을 뺀다 (`ui/screens/map.tsx`)

- `<h2>` 삭제.
- `.node-hint` 줄 삭제 → `text` prop · `pointed` 상태 · `onPointerEnter/Leave/Focus/Blur` 넷이 같이
  죽는다. `MapScreen`이 넘기던 `text={view.text}`도 뗀다(**관측은 안 건드린다** — `view.text`는 엔진에
  그대로 남는다).
- `nodeDetail` 표는 남는다 — `aria-label`이 계속 읽는다.
- `style.css`의 `.node-hint` 규칙(`:438`)도 지운다. `test/ui.test.ts:456`의 「결과 화면에 node-hint가
  없다」는 이제 어디에도 없으므로 그대로 통과한다.

### 3. 지나온 자리는 막힌 자리가 아니다

```css
.map-node:disabled { cursor: default; }
```

지금 서 있는 칸(`.here`)·시작 칸·잠긴 칸 전부가 여기 걸린다. hover 반응은 이미 `button:not(:disabled)`에만
걸려 있으므로(`style.css:261`) 더 막을 것이 없다. **`disabled`는 그대로 둔다** — 못 누르는 것은 사실이고,
테스트와 e2e가 그 값을 읽는다.

### 4. 화려하게 — 새 에셋 0

- 판에 **케니 청동 9-slice**를 두른다 — `.decision-panel.solo`(`:342`)가 쓰는 `panel-border-007-bronze.png`
  그대로다. 경로 화면이 결정 화면 여섯과 같은 그릇이 되는 자리이기도 하다.
- 열린 칸 셋: 지금 `box-shadow` 1px inset(`:400`)뿐이다 → 청동 2px + 바깥 발광. **hover는 밝기만**
  올린다 — 크기·여백을 바꿔 이웃 칸을 밀지 않는다(UI.md).
- 종류별 색(`:395~399`)은 그대로다 — 칸이 커지면 그 색이 저절로 더 보인다.
- **연결선은 안 그린다.** `lane ±1`이라 층마다 최대 7선이고, 선을 그리려면 SVG 층이 새로 생긴다.
  갈래는 열린 칸 셋이 이미 말한다(YAGNI).

### 5. 마커를 천천히 걷게 한다

`markerTransition`(`map.tsx:20`) `0.24s` → **`0.5s`**. 이 값이 곧 화면이 넘어가기까지의 대기다
(`onLayoutAnimationComplete`가 `onEnter`를 부른다) — 12층 × 0.26s = 런당 약 3초가 는다. e2e 완주
시간에 미치는 영향을 검증에서 확인한다. 곡선은 그대로(`--ease-in-out`과 같은 것).

## 하지 않는 것

- **결과 화면의 격자 불변** — `.walkable`이 아니라서 자동으로 그렇다. 두 지역을 나란히 세운 `.8fr`
  열에 760px 판이 들어가면 결과 화면이 무너진다.
- 버튼 → `<i>` 같은 구조 변경 없음(테스트·e2e 계약).
- 관측(`view.text`)·규칙·값·데이터·봇 불변.
- 갈래 연결선·미니맵·스크롤 없음. 판은 여전히 한 화면에 6층이 다 든다.
- 층 번호를 지우지 않는다 — 「몇 층인가」는 위치고, 「6층 × 3갈래」는 격자의 크기다. 지운 것은 뒤쪽이다.

## 완료 정의

- 경로 화면 판이 760px · 칸 72px · 마커 32px이고, 1440×900에서 가로 넘침이 없다.
- 화면에 남은 글자는 층 번호와 칸 이름뿐이다 — 제목 줄과 설명 줄이 없다.
- 지나온 칸·시작 칸에 마우스를 올려도 금지 커서가 안 뜬다.
- 마커가 0.5초에 걸쳐 다음 칸으로 걸어가고, 도착한 뒤에 화면이 넘어간다.
- 결과 화면의 두 격자는 **눈에 띄는 변화가 없다.**
- 스크린 리더는 칸마다 「왼쪽 · 쉼터 · 체력을 회복하거나 카드를 지웁니다」를 그대로 읽는다.
