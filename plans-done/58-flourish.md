# P-58 · 프롭 확대 · 전투 연출

관련 [P-55](55-battle-stage.md) 선행 · [R-42](../reviews/42-mapwalk.md) · 목업 §12~§13 (https://claude.ai/code/artifact/b8958110-728f-4e1f-ad82-c1d1623a293d)

## 배경

프롭 14종(지역당 7, 768×192 4프레임)이 층당 2개 고정 자리에서만 산다 — 만든 값을
못 뽑고 있다. 전투는 P-55로 무대가 됐지만 연출이 없다: 누가 때렸는지 안 보이고(숫자
팝뿐), 턴 경계가 없고, 140px 카드 글자는 작다. **전부 UI 연출이다 — 규칙·값·봇 불변,
`prefers-reduced-motion`이면 전부 즉시 완료.**

## 단계

### 1. 프롭 배치표 (목업 §12 — 전투 3겹은 P-55가 이미 했다)

- **지도**: 패널 좌우 원경 2 + 보스 층(6층) 줄 옆 신호 프롭(지하 `tartarus_glow` ·
  지상 `storm_cloud`) — 끝이 가까워지는 감각.
- **결정 화면 5종**: 패널 좌우 바깥 1쌍. 쉼터만 모닥불 역할(`tartarus_glow`/
  `light_shaft`)을 패널 아래 중앙 96px.
- **신 선택**: 선택된 초상 위 신 테마 프롭 — 제우스 `lightning_afterglow` · 포세이돈
  `droplet` · 아테나 `olive_leaf` · 아레스 `ash` · 아르테미스 `eagle`.
- **인트로**: 메뉴 옆 `wisp` 1~2개 부유. **결과**: 승리 `eagle`+`ribbon`+`light_shaft` /
  패배 `ash`+`chain`+`wisp`.
- 전부 배경과 UI 사이 레이어, pointer-events 없음, 4프레임 steps 루프는 현행
  `.sprite` 재사용.

### 2. 연출 — 우선 여섯 (체감 순)

1. **카드 hover 확대** — 부채꼴에서 가리킨 카드 1.5× 미리보기 + 옆 카드 밀림.
2. **피격 연출** — 공격하는 적 20px 전진(160ms) + 피격자 흰 플래시 120ms + 셰이크
   4px(현행 개입 셰이크 WAAPI 재사용). 관측의 `hits`가 이미 누가 맞았는지 든다.
3. **타겟팅 화살표** — 대상 선택 중 무대 카드 → 커서 점선 베지어(P-55 크로스헤어와
   한 세트).
4. **턴 배너** — 「내 턴 / 적 턴」 슬림 배너 400ms 스윕.
5. **에너지 젬 맥동** — 낼 수 있는 카드가 남으면 1.04 pulse, 에너지 0이면 무채색.
6. **단축키** — D 덱 · J 약속 · T 토큰 사전 · ? 도움말 · Esc 닫기 · E 턴 종료 ·
   1~9 카드. `<dialog>`가 Esc를 이미 든다.

### 3. 연출 — 후순위 여섯 (1·2가 끝나고 남으면)

저체력 비네트(체력 25% 이하 가장자리 숨쉬기) · 프롭 패럴랙스(마우스 X에 원경 ±4px ·
전경 ∓8px) · 승리 슬로모(마지막 적 200ms 저속) · 신 컷인 슬라이드-인(중앙 팝 대체) ·
지도 마커 발자국 · 카드 비행 arc. 하나씩 독립이라 어디서 멈춰도 된다.

## 하지 않는 것

- 새 에셋 생성 없음 — 프롭 14종·컷인·파티클 전부 있는 것만 쓴다.
- 사운드 추가 없음(`sfx.ts` 현행). 연출에 소리를 붙이는 것은 별도 판단.
- 애니메이션 라이브러리 추가 없음 — motion(이미 있음)과 WAAPI로 다 된다.

## 완료 정의

- 프롭이 아홉 화면에서 역할을 갖고 선다(§12 배치표 대로).
- 우선 여섯 연출이 동작하고, `prefers-reduced-motion`에서 전부 즉시 완료된다.
- e2e 완주 — 연출은 전부 시각 레이어라 클릭 계약(`data-*`·`disabled`)이 안 바뀐다.
- 규칙·값·데이터·봇 불변 — 밸런스 게이트는 재측정하지 않는다.
