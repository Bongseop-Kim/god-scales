## 완료 정의

| 케이스 | 기대 |
|---|---|
| 픽스처 덱 10장 + 적 1체 | 1전투가 끝난다 (승리 또는 패배) |
| 같은 시드 2회 실행 | 턴별 상태가 완전히 동일 |
| 턴 시작 | block 소멸, `bulwark` 유지 |
| 피해 순서 | block → `bulwark` → HP |
| 뽑기 더미 고갈 | 버림 더미를 시드 PRNG로 섞어 새 뽑기 더미 |
| 양쪽 더미 고갈 | 드로우하지 않음, 정상 진행 |
| 손패 10장 | 드로우 멈추고 카드는 뽑기 더미에 남음 |
| `exhaust` 카드 사용 | 덱에서 제거, 그 런 동안 재등장 없음 |
| 50턴 초과 | 패배 처리 + `timeout` 기록 |
