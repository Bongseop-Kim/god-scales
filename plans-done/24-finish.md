## 완주가 아직 없는 이유

P-19 시점에는 화면이 갈림길 4클릭뿐이라 완주 E2E를 짤 대상이 없었다. 지금은 여덟 종류 결정이 전부 화면에 있으니 짤 수 있다.

5회차 브라우저 검증은 시드 6이 **6층 보스에서 패배**했다. 원인은 밸런스가 아니라 클릭 정책이다 — 자동 클릭이 "누를 수 있는 첫 카드"를 누르는 최악의 정책이었다.

따라서 E2E 스크립트가 카드를 고르는 규칙이 필요하다. **룰 봇을 옮겨 심지 않는다** — 브라우저에서 봇을 재구현하면 두 번째 진실이 생긴다. 대신 `logs/human/`에 있는 사람 런의 결정 열을 재생하거나, 시드를 훑어 완주하는 하나를 찾는다. 후자가 짧다.

## 순서

```bash
# 1. 배포
npm run build
grep -rE "sk-ant|ANTHROPIC_API_KEY" dist/     # 결과 없음
grep -rl "validate|tune" dist/                # 결과 없음
npm run size                                  # 위반 0
# 커밋·푸시는 사용자가 그 턴에 지시할 때만
curl -sI https://bongseop-kim.github.io/god-scales/ | head -1    # 200

# 2. 완주
open -a Aside
aside repl "..."      # 공개 URL, 12층 완주, 반출 JSON 회수

# 3. 재생 일치
npm run sim -- --replay <반출파일>
cp <반출파일> logs/human/run-36.json
```

`aside repl`만 쓴다. `aside exec`는 모델을 써서 크레딧(402)에 걸린다. 크레딧으로 막히면 헤드리스 검증 + 사용자 육안 확인으로 대체하고 **리뷰에 그렇게 적는다.** 공개 URL 200과 반출 재생 일치는 크레딧 없이 확인된다.
