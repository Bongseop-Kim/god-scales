# P-81 — 소개 영상 (실플레이, 30~60초)

**공모 규정이 정본이다**: 30~60초, 실제 게임 플레이 장면 중심, AI를 이용한 조작·합성 금지, 타인 영상 도용 금지, 실제 플레이 화면 그대로.

규정에 따라 뺀 것 — **나레이션 TTS 없음**(AI 합성), **다중 영상 그리드 없음**(합성 화면), **자막·텍스트 오버레이 없음**(화면 무가공, 사용자 확정). 타이틀과 마무리는 게임 자체 화면(인트로·결과)이 대신한다 — 게임 UI와 신 대사 자막이 이미 화면 안에 있어 설명이 따로 필요 없다.

허용되는 편집은 **컷뿐이다**. 배속·슬로모·화면 합성·오버레이를 쓰지 않는다. 오디오는 게임이 그 순간 실제 재생한 원본 에셋을 얹는다(사용자 확정) — AI가 아니고 게임 사운드 그대로다.

## 방법

aside `page.video()`는 쓰지 않는다 — 1.0.728.1에서 녹화를 켜면 데몬이 죽는 것을 4회 재현했다.
역할을 가른다: **클릭은 aside, 녹화는 mac(`screencapture -v`), 편집은 ffmpeg.**

1. **ffmpeg 수리** — `brew reinstall x265 ffmpeg`. (완료)
2. **촬영** — `tools/e2e.ts`의 클릭 정책을 단발 스텝 드라이버로 옮겨(R-80 방식) aside repl로 게임을 실플레이시키고, 그동안 mac이 화면을 녹화한다. Aside 창을 고정 배치하고 창 영역만 ffmpeg `crop`으로 남긴다. 결정 사이에 짧은 대기를 넣어 사람 손 속도로 보이게 한다 — 배속 편집이 금지라 원본 속도가 곧 화면 속도다.
3. **편집** — ffmpeg `trim`+`concat`(컷)과 오디오 `adelay`+`amix`만. 출력 `submission/trailer.mp4`, 1920×1080 H.264+AAC, **30~60초 안**(목표 50±5초).

## 촬영 — 테이크 하나

완주 런 한 테이크(e2e 시드 `?seed=312`, 제우스+아테나, 배분 65)에서 전부 나온다:
인트로 타이틀 → 업적 모달(시작 전 열고 닫기) → 신 선택 → 맵 → 전투·개입 컷인 → 과업/분노 → 은혜 → 사전(런 중 카드 도감 스크롤) → 결과.

촬영 중 폴링 로그를 stdout에 남긴다 — phase 전환 시각, 개입 컷인 발생 시각, **재생 호출된 음성 파일 경로(`/audio/voice/*.m4a`)**. 녹화 시작 시각과의 차가 편집 타임코드다. 개입 컷인은 창이 짧으니(500ms~3s) R-80처럼 `.fx.{단계}`·`.voice.l2/l3`를 폴링한다.

시드 312가 완주를 보장하는 건 e2e와 같은 클릭 정책일 때다 — 사전 열기·대기 삽입은 결정에 영향이 없으므로 완주가 유지된다. 죽으면 e2e 주석의 예비 시드(575·369·279)로 재촬영.

## 컷 구성 (총 ~50초, 전부 원속도 컷)

| 구간 | 화면 |
|---|---|
| 0–4s | 게임 인트로 타이틀 화면 |
| 4–10s | 업적 모달 → 신 선택(다섯 중 둘) |
| 10–16s | 맵 — 12층 세 갈래 |
| 16–32s | 전투 — 카드 → 표적 → 토큰 → **신 개입 컷인**(대사 자막·연출이 게임 화면 안에 있다) |
| 32–38s | 과업 선택 → 상대 신 호의 하락·분노 |
| 38–44s | 은혜 3택 |
| 44–49s | 게임 사전 — 카드 도감 스크롤(카드 풀의 폭) |
| 49–54s | 결과 화면(승리 · 12/12층) |

컷 경계는 폴링 로그 타임코드로 정하고, 각 구간은 해당 장면의 연속 원본이다.

## 오디오 — 게임이 실제 재생한 원본 에셋

| 트랙 | 소스 | 배치 |
|---|---|---|
| BGM | `audio/`의 게임 BGM — **런 중 실제 재생되는 곡**을 확인해 그 곡을 쓴다 | 전 구간, 끝 페이드아웃 |
| 신 대사 음성 | `audio/voice/*.m4a` — 폴링 로그에 남은, 그 컷에서 실제 재생 호출된 파일 | 개입 컷인 컷과 동기 |
| SFX | `audio/`의 타격·카드음 | 선택 — 전투 컷의 타격 몇 곳만, 동기가 어긋나면 뺀다 |

전부 게임 저장소의 원본 파일이고 AI 생성물이 아니다. 게임이 그 장면에서 튼 소리를 그대로 복원하는 것이다.

## 리스크

- `screencapture` 화면 기록 권한 — 첫 실행에서 macOS 프롬프트, 사용자 승인 한 번 필요할 수 있다.
- Aside 데몬 간헐 사망 — 테이크 시작 전 `listBrowserTabs()`로 확인, 죽으면 재촬영.
- 결정 간 대기를 넣어도 컷인·전투 연출 타이밍은 게임이 정한다 — 구간이 짧게 나오면 컷 구성에서 이웃 구간을 늘려 30초 하한을 지킨다.
